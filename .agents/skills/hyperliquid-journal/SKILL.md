---
name: hyperliquid-journal
description: Update the repository trading journal from Hyperliquid Trade History, Balances, Positions and Open orders, reconcile new executions and costs, and record lessons from actual trades or user feedback.
---

Read `AGENTS.md`, `PROFILE.md`, `docs/journal.md` and `memory/lessons.md`. Work in this repository and respond in French. Default the requested day to Asia/Shanghai; trades around midnight need their actual local day, not the browser's unverified timezone.

Read `docs/browser.md` for the tested native-browser fallback. A portfolio displaying `Connect` does not provide current account evidence.

1. Open the connected `https://app.hyperliquid.xyz/portfolio`. Verify the intended main/subaccount without retaining its address. Read **Balances**, **Positions**, **Open orders**, and **Trade History**. Observe equity, available-to-trade amount, collateral currency, holds/reservations, unrealized PnL, position size/margin mode/liquidation and active protective orders. Record each tab's observation time. Paginate/export Trade History through an overlap with the last imported execution; a first page is not complete history. Also read funding and deposits/withdrawals when needed for reconciliation.
2. Prefer stable exchange fill IDs and exact values. A CSV export is source data: inspect its headers, numeric units, timezone and whether rows are aggregated before adapting it to `templates/journal-import.json`. Follow `docs/journal.md`. Do not make up fill IDs, entry prices or leverage. No browser access: continue independent journal work and ask for the missing account access or public address. If a public address is provided, use `fetch-history` and `fetch-account` with an ephemeral environment variable; no signing key is needed. Read-only API fallback must be labeled and browser cross-check stays pending.
3. Create an observed import bundle in `.local/`, including account snapshot and explicit coverage. Run `python3 scripts/desk.py journal-import <path>` and `python3 scripts/desk.py journal-day YYYY-MM-DD` for each affected local day. Verify duplicate imports add zero records. Keep exact fills even when the daily report summarizes completed episodes. Inspect partial entries/exits, reversals, overnight trades, missing openings and fee currencies. Do not equate fill counts with trade counts.
4. Reconcile account changes: equity delta = realized PnL - all fees + funding + external cashflows + change in unrealized PnL + other verified valuation effects, using consistent account scope. If either boundary snapshot, cashflow or valuation is missing, record the unexplained difference and `not_established`/`partial`. Never force the journal to match a displayed number. Balances supersede reconstructed arithmetic for the current observed account state.
5. Write or append a brief human review in `journal/reviews/YYYY-MM-DD.md`. Link observed episodes/fill IDs to the pre-trade report, execution notes and user feedback. Record plan adherence, timing, reason for exit, known duration, fees/funding drag and what mattered. Planned SL, actual leverage, initial risk, MAE/MFE and R remain unknown without contemporaneous evidence. Separate a loss from a bad decision and a win from a good process. Do not assign funding to a trade unless its coin/exposure interval is known.
6. Update `memory/lessons.md` only with useful evidence-linked observations or hypotheses. Include supporting and contradicting trades, sample size and next test; avoid claiming an edge from a few trades. Review expectancy in net R, average win/loss, drawdown, time-in-trade, costs and regime only on sufficiently complete comparable episodes. Never retroactively edit a pre-trade thesis to fit its outcome.

Finish with current observed balance and its time/scope, newly added fills and completed trades, net accounting with coverage limits, and at most a few actionable process lessons. A no-trade day can simply refresh the account. Preserve human reviews when regenerating machine output. Do not publish financial records remotely as part of the daily update unless requested.
