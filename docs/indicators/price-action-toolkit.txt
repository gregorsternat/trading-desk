//@version=3
// Price Action Toolkit
//
// One indicator, every price-action concept: market structure (BOS / CHoCH /
// CHoCH+ on an internal and a swing horizon, pivot letters, candle tint),
// order blocks with a buy / sell split and breakers, pivot trend lines and
// chart patterns, equal highs / lows, wick sweeps (liquidity grabs),
// imbalances (FVG / volume imbalance / opening gap), premium / discount range
// zones, and an Order Flow tab that grades those objects with the sided
// volume and footprint ladder this chart carries (see the ORDER FLOW section:
// every grade is an annotation on an object the classic rules already draw,
// and stands down silently where a series is empty). A user adds this one
// script and gets everything; each feature family is a tab in the settings
// with its own display toggle, and every feature evaluates on bar close.
//
// Everything is built on ONE primitive, computed once per bar and shared:
//
//   Swing detector (leg state machine). For a lookback L, the bar L back is a
//   swing high when its high strictly clears the highs of every one of the L
//   bars that followed it, a swing low when its low strictly undercuts all of
//   their lows (a same-bar tie resolves to the high). The leg flips on that
//   bar, so swings confirm exactly L bars late and strictly alternate. Two
//   instances always run: the internal lookback (default 5) and the swing
//   lookback (default 50). The order-block detector rides the internal
//   instance at its default lookback (or the swing instance, or a third
//   instance when its own lookback differs from both). Consumers: structure
//   (both horizons), wick sweeps (internal), order blocks, range zones and
//   the range extremes (swing).
//
//   ATR(200): a Wilder average of true range, hardcoded 200, seeded with the
//   cumulative average over the first 200 bars so a cold start converges
//   instead of waiting. Consumers: order-block height cap, equal-level
//   tolerance (0.1 x), trend-line zones (0.25 x), pattern zones (0.5 x),
//   minimum gap height.
//
// Equal highs / lows (two-sided 3- or 15-bar fractal pivots), trend lines
// (two-sided 2-bar wick pivots) and patterns (symmetric body pivots at 2 x
// scale) are different pivot definitions and keep their own small detectors;
// they do not ride the leg machine.
//
// Original implementation. Every feature is covered by a deterministic test harness on two
// engine versions.
//
// Presentation: what is drawn where and what a tag says follows the usual
// charting convention for these concepts; the palette, line grammar and
// shapes are ours. One palette across the toolkit (mint / raspberry internal
// structure, azure / amber swing structure, periwinkle / tangerine order
// blocks with lilac / gold breakers, steel-blue / soft-red trend lines, sage /
// clay pattern lines, orchid / periwinkle equal levels, jade / coral sweeps,
// sky / blush gaps, raspberry / slate / mint zones), one line grammar
// (dashed = a broken level, a midpoint line or a retired line; dotted = a
// companion edge or an equal-level connector; solid = a live line or a box
// edge), translucent fills everywhere, tiny text tags placed off the line
// they annotate, two-tier pivot chips (HH / LL filled, LH / HL outlined),
// wick pockets on sweep bars, and bounded drawing history everywhere. Every
// extra marker sits behind its own toggle, off by default (the plain look):
// structure break dots + order-block pins / breaker crosses (Event dots and
// pins), sweep tip triangles + swept-level rails (Sweep markers), gap fill
// crosses (Fill marks), trend-line break crosses (Line break marks), the
// source-candle highlight. Series markers cost no drawings.
//
// Alpha lives in the color string (opacity(hex, percent) -> rgba): the chart
// renderer reads a drawing's color / backgroundColor verbatim, ignores a
// box's fillOpacity, and clamps the generic opacity prop to 0..1, so percent
// values passed as opacity render fully opaque. Linefills take their alpha as
// opacity on the 0..1 scale (the engine's own default is 0.25).
//
// Drawing budget (engine cap: 500 per kind, shared by every feature here).
// Every history is a FIFO that deletes its oldest drawing BEFORE creating a
// new one, so the caps below are hard peaks, not targets. N = Blocks kept on
// chart (the newest N blocks over both sides, <= 20):
//   labels: structure tags 100 internal + 30 swing, pivot letters 300 - 2N
//           (290 at the default 5, 260 at the cap), equal-level tags 50, OB
//           readouts N (<= 20), zone tags 3, range-extreme tags 2  -> <= 485
//   lines:  structure 100 + 30, equal-level connectors 50, swept-level rails
//           60, OB midpoint lines N (<= 20), trend lines 4 x kept + 4
//           (<= 84), pattern lines 4, gap midpoint lines 120 (the newest
//           120 live gaps), range extremes 2                    -> <= 470
//   boxes:  order blocks 5N (body, breaker segment, two split bars, optional
//           source-candle highlight; <= 100), gaps 200 (the buffer), zones 3
//                                                              -> <= 303
//   linefills: trend lines 2 x kept + 2 (<= 42), pattern 2      -> <= 44
// The Order Flow grades add no drawings: they change a tag's text / tone, a
// gap box's edge / fill / tooltip, or the zone levels, and add series markers.
// Data sources: candles (1 slot) + the footprint ladder (1) = 2 weighted
// slots; the ladder is fetched only while an Order Flow toggle is on, and its
// per-bar buy / sell totals stand in for the taker split (same tape, one
// source, an O(1) read: a buy_sell_volume read costs O(history) per bar in
// this engine). Engine time: the break grade (on by default) reads three
// accessors per bar; the composite ladder behind the gap grade and the
// value-area zones (both opt-in) walks every footprint bucket twice per bar,
// about 0.1 ms per bar measured, which is why those two ship off.
define(title="Price Action Toolkit", position="onchart", axis=false);

// ATR(200): Wilder RMA of true range, cumulative-seeded (running sum over the
// first 200 bars) so a cold start converges instead of waiting.
persist atrSum = 0;
persist atr200 = 0;
var tr0 = d.high[0] - d.low[0];
if (barNo > 0) {
  tr0 = max(d.high[0] - d.low[0], max(abs(d.high[0] - d.close[1]), abs(d.low[0] - d.close[1])));
}
if (barNo < 200) {
  atrSum = atrSum + tr0;
  atr200 = atrSum / (barNo + 1);
} else {
  atr200 = (atr200 * 199 + tr0) / 200;
}
// Text tags sit off the level they annotate by this much (above a bullish
// level, below a bearish one): a price offset that scales with the market,
// since drawings cannot be offset in pixels.
var tagLift = 0.4 * atr200;
// Bar time by bar index, for tags placed at the midpoint bar of a segment.
persist tHist = [];
tHist.push(d.time[0]);
func midBarT(fromBar, toBar) {
  return tHist[floor((fromBar + toBar) / 2)];
}

// Swing detector instances. Rolling windows are TA builtins, so they stay
// unconditional; the leg state lives in one persist array indexed by
// instance (0 internal, 1 swing, 2 order-block length when it differs).
// swingStep returns 1 on a newly registered swing HIGH, 2 on a swing LOW,
// 0 otherwise; the caller reads the pivot's value and time at offset len.
var iWinHigh = highest(source=d.high, period=iLen);
var iWinLow = lowest(source=d.low, period=iLen);
var sWinHigh = highest(source=d.high, period=sLen);
var sWinLow = lowest(source=d.low, period=sLen);
var obWinHigh = highest(source=d.high, period=obLength);
var obWinLow = lowest(source=d.low, period=obLength);
persist swLeg = [2, 2, 2];
func swingStep(id, candHigh, candLow, winHigh, winLow) {
  var next = swLeg[id];
  if (candHigh > winHigh) { next = 0; }
  else {
    if (candLow < winLow) { next = 1; }
  }
  var evt = 0;
  if (next == 0 && swLeg[id] != 0) { evt = 1; }
  if (next == 1 && swLeg[id] != 1) { evt = 2; }
  swLeg[id] = next;
  return evt;
}
var iEvt = 0;
var sEvt = 0;
var obEvt = 0;
if (barNo >= iLen) { iEvt = swingStep(0, d.high[iLen], d.low[iLen], iWinHigh, iWinLow); }
if (barNo >= sLen) { sEvt = swingStep(1, d.high[sLen], d.low[sLen], sWinHigh, sWinLow); }
if (obShow && barNo >= obLength) {
  if (obLength == iLen) { obEvt = iEvt; }
  else {
    if (obLength == sLen) { obEvt = sEvt; }
    else { obEvt = swingStep(2, d.high[obLength], d.low[obLength], obWinHigh, obWinLow); }
  }
}

// ============================================================================
// ORDER FLOW: footprint reads + composite ladder (shared by the grades)
// ============================================================================
// The footprint ladder is fetched only while an Order Flow toggle is on; its
// per-bar buy / sell totals give the bar's delta share (the same trades the
// taker split reports). Per bar, three O(1) accessor reads (totals, bucket
// count) and a handle on the bar's row (the break grade walks its buckets
// on event bars only), plus, while a ladder consumer is on, the composite
// ladder = one cell per footprint bucket, volume summed over the last Ladder
// lookback bars: a dense array over the bucket grid (ladBase = the cell key
// of index 0), this bar's buckets added and the buckets of the bar leaving
// the window (read back off the series' own history, vp[lookback]) taken
// out, trimmed at both ends. The two bucket loops are the only per-bucket
// work in the script and are kept to four statements each. Every read
// degrades to "no data" (na / 0) when a series is empty, and every consumer
// falls back to the plain behavior on "no data".
var ofAny = ofBreakGrade || ofGapGrade || ofValueZones;
var ofLadderOn = ofGapGrade || ofValueZones;
var ofThr = ofFlowThreshold / 100;
var ofHasFlow = false;  // this bar carries a sided split (footprint totals > 0)
var ofShare = 0;        // (buy - sell) / (buy + sell), -1..1; 0 without data
var ofRow = [];         // this bar's footprint row [time, [low, high, buy, sell], ...]; the break grade walks it on event bars only
persist ladStep = 0;    // price per ladder cell (the footprint bucket height)
persist ladFirstBar = -1; // the bar the grid was learnt on (earlier bars never entered the ladder)
persist ladBase = 0;    // cell key of ladVol[0]
persist ladVol = [];    // cell volumes, dense: key = ladBase + index; both ends always hold volume (trimmed every bar)
var ladStep2 = 0;       // 2 x ladStep: a bucket's cell key = floor((low + high) / ladStep2), the cell its midpoint is in
// Grow the dense array to hold key; returns its index, or -1 for a stray
// print thousands of cells off the grid.
func ladIndex(key) {
  var lix = -1;
  if (ladVol.length == 0) { ladBase = key; ladVol.push(0); lix = 0; }
  else {
    if (key < ladBase) {
      if (ladBase - key <= 4000) {
        for (var lu = ladBase - key; lu > 0; lu = lu - 1) { ladVol.unshift(0); }
        ladBase = key; lix = 0;
      }
    } else {
      if (key - ladBase - ladVol.length < 4000) {
        for (var lp = key - ladBase - ladVol.length + 1; lp > 0; lp = lp - 1) { ladVol.push(0); }
        lix = key - ladBase;
      }
    }
  }
  return lix;
}
if (ofAny) {
  timeseries vp = source("volume_profile", symbol=currentSymbol, exchange=currentExchange, ticksPerBar=5, currency="USD");
  var ofTot = vpTotal(vp);
  var ofDel = vpDelta(vp);
  var ofNb = vpBucketCount(vp);
  if (isnum(ofTot) && isnum(ofDel) && ofTot > 0) { ofHasFlow = true; ofShare = ofDel / ofTot; }
  if (isnum(ofNb) && ofNb > 0) { ofRow = vp[0]; } else { ofNb = 0; }
  if (ofLadderOn) {
    if (ladStep == 0 && ofNb > 0) {
      var ofFb = ofRow[1];
      if (ofFb[1] > ofFb[0]) { ladStep = ofFb[1] - ofFb[0]; ladFirstBar = barNo; }
    }
    if (ladStep > 0) {
      ladStep2 = 2 * ladStep;
      // this bar's buckets in: the grid is grown once for the bar's price span
      // (the min / max over its buckets, whatever their order), then every
      // bucket lands on its cell with no per-bucket bounds check. A bar whose
      // span cannot be gridded (thousands of cells off: garbage data) is skipped.
      if (ofNb > 0) {
        var ofKLo = floor(vpPriceLow(vp) / ladStep);
        var ofKHi = floor(vpPriceHigh(vp) / ladStep);
        if (ladVol.length == 0 || ofKLo < ladBase || ofKHi >= ladBase + ladVol.length) { ladIndex(ofKLo); ladIndex(ofKHi); }
        if (ofKLo >= ladBase && ofKHi < ladBase + ladVol.length) {
          for (var ofI = 1; ofI <= ofNb; ofI = ofI + 1) {
            var ofBk = ofRow[ofI];
            var ofBv = ofBk[2] + ofBk[3];
            if (ofBv > 0) { var ofIx = floor((ofBk[0] + ofBk[1]) / ladStep2) - ladBase; ladVol[ofIx] = ladVol[ofIx] + ofBv; }
          }
        }
      }
      // the bar leaving the window: its buckets, keyed the same way, come back out
      if (barNo - ofLadderLookback >= ladFirstBar) {
        var ofOldRow = vp[ofLadderLookback];
        var ofOldN = ofOldRow.length;
        var ofLen = ladVol.length;
        for (var ofO = 1; ofO < ofOldN; ofO = ofO + 1) {
          var ofOb = ofOldRow[ofO];
          var ofOv = ofOb[2] + ofOb[3];
          if (ofOv > 0) {
            var ofOx = floor((ofOb[0] + ofOb[1]) / ladStep2) - ladBase;
            if (ofOx >= 0 && ofOx < ofLen) { var ofNv = ladVol[ofOx] - ofOv; ladVol[ofOx] = ofNv < 0.000001 ? 0 : ofNv; }
          }
        }
      }
      // keep both ends on volume (the value area's neighbor test and the
      // range clamp read the array's ends as the ladder's extent)
      while (ladVol.length > 0 && ladVol[0] <= 0) { ladVol.shift(); ladBase = ladBase + 1; }
      while (ladVol.length > 0 && ladVol[ladVol.length - 1] <= 0) { ladVol.pop(); }
    }
  }
}
var ladHas = ofLadderOn && ladStep > 0 && ladVol.length > 0;

// ---------------------------------------------------- break grading (PAC-1) --
// grade: 0 no data, 1 confirmed, 2 thin (low participation), 3 run (a CHoCH
// whose break bar traded against it). dir = +1 bullish break, -1 bearish.
// Confirmed = the bar's delta share in the break's direction reaches the
// threshold AND the footprint beyond the broken level does not oppose it
// (buckets fully beyond the level, buy - sell in the break's direction).
// Closed bars only: the app re-runs the forming bar on every tick from
// scratch, so a grade read off the live bar's row would rewrite the tag as
// the taker split fills in (thin / run / plain flicker). While the break bar
// forms the tag stays plain (0); the grade is read once, when the bar closes
// (isConfirmed), from the closed row, and the tooltip carries those numbers.
persist ofTipShare = 0; persist ofTipLevel = 0; persist ofTipLevelHas = false;
func ofGradeBreak(dir, level, isChoch) {
  if (ofBreakGrade == false || ofHasFlow == false || isConfirmed == false) { return 0; }
  var ofS = ofShare * dir;
  var lvBuy = 0; var lvSell = 0;
  for (var lq = 1; lq < ofRow.length; lq = lq + 1) {
    var lvBk = ofRow[lq];
    var lvBeyond = dir > 0 ? lvBk[0] >= level : lvBk[1] <= level;
    if (lvBeyond) { lvBuy = lvBuy + lvBk[2]; lvSell = lvSell + lvBk[3]; }
  }
  ofTipShare = ofS;
  ofTipLevelHas = lvBuy + lvSell > 0;
  ofTipLevel = ofTipLevelHas ? ((lvBuy - lvSell) / (lvBuy + lvSell)) * dir : 0;
  if (isChoch && ofS <= 0 - ofThr) { return 3; }
  if (ofS >= ofThr && (ofTipLevelHas == false || ofTipLevel >= 0)) { return 1; }
  return 2;
}
func ofPct(x) {
  var pctR = round(100 * x);
  return (pctR >= 0 ? "+" : "") + tostring(pctR) + "%";
}
func ofGradeWord(g) {
  return g == 1 ? "confirmed" : (g == 2 ? "thin" : "run");
}
// The tag itself: plain when ungraded (g == 0), else the suffix, a dimmer
// tone for thin, and the numbers in the tooltip.
func ofTag(x, y, text, col, size, g) {
  if (g == 0) { return label.new(x, y, text, {color: col, bgcolor: "transparent", size: size}); }
  var tipTxt = "delta share " + ofPct(ofTipShare) + (ofTipLevelHas ? ", beyond the level " + ofPct(ofTipLevel) : "") + ": " + ofGradeWord(g);
  var tagTxt = g == 1 ? text : text + " " + ofGradeWord(g);
  return label.new(x, y, tagTxt, {color: g == 2 ? opacity(col, 55) : col, bgcolor: "transparent", size: size, tooltip: tipTxt});
}
// per-bar alert flags (any horizon, drawn or not)
var ofThinBull = false; var ofThinBear = false; var ofRunBull = false; var ofRunBear = false;

// ---------------------------------------------------- gap grading (PAC-4) ---
// verdict at creation: 0 plain, 1 fast fill (every cell inside the gap under
// half the ladder's typical cell), 2 sticky (a cell at least 1.5 x the
// typical cell). Typical = mean of the ladder's non-empty cells; a cell is
// inside the gap when its midpoint is.
persist gapTipMax = 0; persist gapTipTypical = 0;
func ofGapVerdict(bottom, top) {
  var gv = 0;
  if (ofGapGrade && ladHas) {
    var gapNz = 0; var gapSum = 0;
    for (var gc = 0; gc < ladVol.length; gc = gc + 1) { if (ladVol[gc] > 0) { gapNz = gapNz + 1; gapSum = gapSum + ladVol[gc]; } }
    if (gapNz > 0) {
      var gapTyp = gapSum / gapNz;
      var gapMx = 0;
      // the gap's cells: every cell whose midpoint lies inside [bottom, top]
      var gkLo = math.ceil(bottom / ladStep - 0.5); var gkHi = floor(top / ladStep - 0.5);
      for (var gk = gkLo; gk <= gkHi; gk = gk + 1) {
        var gix = gk - ladBase;
        if (gix >= 0 && gix < ladVol.length && ladVol[gix] > gapMx) { gapMx = ladVol[gix]; }
      }
      gapTipMax = gapMx; gapTipTypical = gapTyp;
      if (gapMx >= 1.5 * gapTyp) { gv = 2; }
      else { if (gapMx < 0.5 * gapTyp) { gv = 1; } }
    }
  }
  return gv;
}

// ============================================================================
// MARKET STRUCTURE (internal + swing horizons, letters, candle coloring)
// ============================================================================
// A confirmed level is broken at most once, by CLOSE strictly through it. A
// break with the prevailing trend prints BOS; against it, the trend flips and
// prints CHoCH (the leg into the break was still extending past the prior
// opposite swing) or CHoCH+ (that leg had already failed to reach it). The
// leg is measured on raw highs / lows from the bar after the broken swing's
// pivot up to the bar before the break.
func classShown(disp, isBos, isPlus) {
  if (disp == "None") { return false; }
  if (disp == "All") { return true; }
  if (disp == "BOS") { return isBos; }
  if (disp == "CHoCH (All)") { return isBos == false; }
  if (disp == "CHoCH+") { return isBos == false && isPlus; }
  if (disp == "CHoCH") { return isBos == false && isPlus == false; }
  return true;
}

if (barNo >= iLen) {

      // two-tier chip: HH (trend continuation) filled, LH outlined

  }
  if (iEvt == 2) {

      iMarks.push(label.new(iBtmT, iBtmY, iBtmMark,

    else {
      var iRefTopHas = 0; var iRefTopY = 0;

      else {
        if (iPrevTopHas == 1 && iPrevTopPivot < iBtmPivot) { iRefTopHas = 1; iRefTopY = iPrevTopY; }

    else {
      var sRefBtmHas = 0; var sRefBtmY = 0;
      if (sBtmHas == 1 && sBtmPivot < sTopPivot) { sRefBtmHas = 1; sRefBtmY = sBtmY; }
      else {
        if (sPrevBtmHas == 1 && sPrevBtmPivot < sTopPivot) { sRefBtmHas = 1; sRefBtmY = sPrevBtmY; }
      }
      if (sRefBtmHas == 1 && sLegMin < sRefBtmY) { sBullChoch = true; } else { sBullChochPlus = true; }
    }

  }
  if (sBtmHas == 1 && sBtmCrossed == 0 && d.close[0] < sBtmY) {

    if (sTrend == -1) { sBearBos = true; }
    else {
      var sRefTopHas = 0; var sRefTopY = 0;

      else {
        if (sPrevTopHas == 1 && sPrevTopPivot < sBtmPivot) { sRefTopHas = 1; sRefTopY = sPrevTopY; }
      }
      if (sRefTopHas == 1 && sLegMax > sRefTopY) { sBearChoch = true; } else { sBearChochPlus = true; }
    }
    sTrend = -1;
  }

  if (sTopHas == 1 && sTopCrossed == 0) { sLegMin = min(sLegMin, d.low[0]); }
  if (sBtmHas == 1 && sBtmCrossed == 0) { sLegMax = max(sLegMax, d.high[0]); }
}

// ============================================================================
// PREMIUM / DISCOUNT ZONES (anchored by the swing-length detector)
// ============================================================================
// The zone high re-anchors to each newly registered swing high and ratchets
// up with price in between; the zone low mirrors it. The level series are a
// fixed partition of that trailing range (the four interior levels):
// premium bottom at 95%, equilibrium 47.5% .. 52.5%, discount top at 5%.
// The drawn bands straddle their anchors:
// premium = the swing high +- 5% of the range, discount = the swing low
// +- 5%, equilibrium = the middle 5%. Seeded from the first bar so the
// bands cover the whole chart; the seed converges at the first re-anchor.
// Each edge remembers the bar that set it (the range's anchors) and that
// bar's volume (the strong / weak readout).
persist zoneHigh = 0;
persist zoneLow = 0;
persist zoneHighT = 0;
persist zoneLowT = 0;
persist zoneHighVol = 0;
persist zoneLowVol = 0;
if (barNo == 0) {

  zoneLow = d.low[0]; zoneLowT = d.time[0]; zoneLowVol = d.volume[0];
}
if (sEvt == 1) { zoneHigh = d.high[sLen]; zoneHighT = d.time[sLen]; zoneHighVol = d.volume[sLen]; }
if (sEvt == 2) { zoneLow = d.low[sLen]; zoneLowT = d.time[sLen]; zoneLowVol = d.volume[sLen]; }
if (d.high[0] > zoneHigh) { zoneHigh = d.high[0]; zoneHighT = d.time[0]; zoneHighVol = d.volume[0]; }
if (d.low[0] < zoneLow) { zoneLow = d.low[0]; zoneLowT = d.time[0]; zoneLowVol = d.volume[0]; }

var premiumBottom = zoneLow + 0.95 * zoneRange;
var equilibriumTop = zoneLow + 0.525 * zoneRange;
var equilibriumBottom = zoneLow + 0.475 * zoneRange;
var discountTop = zoneLow + 0.05 * zoneRange;
var premiumTop = zoneHigh + 0.05 * zoneRange;
var discountBottom = zoneLow - 0.05 * zoneRange;
// Value-area mode (Order Flow): equilibrium = the cells around the ladder's
// point of control, inside the trailing swing range, that hold 70% of the
// range's composite volume (grown one cell at a time toward the heavier
// neighbor); premium = above it up to the range high, discount = below it
// down to the range low. Stands down to the classic lattice above when the
// ladder holds no volume inside the range.
var vaOn = false; var vaHigh = 0; var vaLow = 0; var vaPoc = 0;
if (ofValueZones && ladHas && zoneRange > 0) {
  var vaKLo = max(floor(zoneLow / ladStep), ladBase);
  var vaKHi = min(floor(zoneHigh / ladStep), ladBase + ladVol.length - 1);
  if (vaKHi >= vaKLo) {
    var vaTot = 0; var vaPk = vaKLo; var vaPv = -1;
    for (var vaK = vaKLo; vaK <= vaKHi; vaK = vaK + 1) {
      var vaCv = ladVol[vaK - ladBase];
      vaTot = vaTot + vaCv;
      if (vaCv > vaPv) { vaPv = vaCv; vaPk = vaK; }
    }
    if (vaTot > 0) {
      var vaLoK = vaPk; var vaHiK = vaPk; var vaAcc = vaPv; var vaTarget = 0.7 * vaTot;
      while (vaAcc < vaTarget && (vaLoK > vaKLo || vaHiK < vaKHi)) {
        var vaBelow = vaLoK > vaKLo ? ladVol[vaLoK - 1 - ladBase] : -1;
        var vaAbove = vaHiK < vaKHi ? ladVol[vaHiK + 1 - ladBase] : -1;
        if (vaAbove > vaBelow) { vaHiK = vaHiK + 1; vaAcc = vaAcc + vaAbove; }
        else { vaLoK = vaLoK - 1; vaAcc = vaAcc + vaBelow; }
      }
      vaOn = true;
      vaLow = max(vaLoK * ladStep, zoneLow);
      vaHigh = min((vaHiK + 1) * ladStep, zoneHigh);
      vaPoc = (vaPk + 0.5) * ladStep;
    }
  }
}
if (vaOn) {
  premiumBottom = vaHigh; equilibriumTop = vaHigh; equilibriumBottom = vaLow; discountTop = vaLow;
  premiumTop = zoneHigh; discountBottom = zoneLow;
}
var pdPremTip = vaOn ? "Premium: above the value area, up to the swing high" : "Premium: the swing high +- 5% of the trailing swing range";
var pdEqTip = vaOn ? "Equilibrium: the value area (70% of the composite footprint volume inside the trailing swing range)" : "Equilibrium: middle 5% of the trailing swing range";
var pdDiscTip = vaOn ? "Discount: below the value area, down to the swing low" : "Discount: the swing low +- 5% of the trailing swing range";

// Three bands at the right edge, drawn once on the last bar and re-anchored

  } else {

    pdBoxes[1].set_lefttop(pdLeft, equilibriumTop); pdBoxes[1].set_rightbottom(pdRight, equilibriumBottom);

  }
}
// Optional full-history readout of the same levels (thin dotted lines, no

// ------------------------------------------ strong / weak high / low ----

// LIQUIDITY: EQUAL HIGHS / LOWS + LIQUIDITY GRABS
// ============================================================================
// Equal H/L: two-sided fractal pivots with a fixed side length (3 Short-Term,
// 15 Long-Term). Left window may tie the pivot, right window must stay
// strictly beyond; a pivot confirms N bars late. Consecutive same-side pivots
// within 0.1 x ATR(200) are equal and are drawn retrospectively as a pool.
var eqN = eqhlTerm == "Long-Term" ? 15 : 3;
timeseries eqWinHigh = highest(source=d.high, period=eqN);
timeseries eqWinLow = lowest(source=d.low, period=eqN);
persist eqPhHas = false; persist eqPhVal = 0; persist eqPhT = 0; persist eqPhBar = 0;
persist eqPlHas = false; persist eqPlVal = 0; persist eqPlT = 0; persist eqPlBar = 0;

var eqlFromT = 0; var eqlFromVal = 0; var eqlToT = 0; var eqlToVal = 0; var eqlFromBar = 0; var eqlToBar = 0;
if (barNo >= 2 * eqN) {
  var eqPvH = d.high[eqN];
  var eqPvL = d.low[eqN];
  var eqLeftMaxH = eqWinHigh[eqN + 1];
  var eqRightMaxH = eqWinHigh[0];
  var eqLeftMinL = eqWinLow[eqN + 1];
  var eqRightMinL = eqWinLow[0];
  var eqIsPH = eqLeftMaxH <= eqPvH && eqRightMaxH < eqPvH;
  var eqIsPL = eqLeftMinL >= eqPvL && eqRightMinL > eqPvL;
  if (eqIsPH) {
    if (eqPhHas && abs(eqPvH - eqPhVal) < 0.1 * atr200) {
      eqhFire = true;
      eqhFromT = eqPhT; eqhFromVal = eqPhVal; eqhToT = d.time[eqN]; eqhToVal = eqPvH;
      eqhFromBar = eqPhBar; eqhToBar = barNo - eqN;

    eqPhHas = true; eqPhVal = eqPvH; eqPhT = d.time[eqN]; eqPhBar = barNo - eqN;
  }
  if (eqIsPL) {
    if (eqPlHas && abs(eqPvL - eqPlVal) < 0.1 * atr200) {
      eqlFire = true;
      eqlFromT = eqPlT; eqlFromVal = eqPlVal; eqlToT = d.time[eqN]; eqlToVal = eqPvL;
      eqlFromBar = eqPlBar; eqlToBar = barNo - eqN;
    }
    eqPlHas = true; eqPlVal = eqPvL; eqPlT = d.time[eqN]; eqPlBar = barNo - eqN;
  }
}

// Grabs: each internal swing arms one level per side (replaced by each new

var bearGrabLvl = 0; var bearGrabT = 0;

// ============================================================================
// ORDER BLOCKS + BREAKERS
// ============================================================================
// Each swing high arms a bullish break level, each swing low a bearish one.
// The first bar whose CLOSE clears an armed level creates a block: the source
// candle is the lowest low (bullish) / highest high (bearish) strictly between
// the swing pivot and the break bar (break bar excluded, oldest wins ties).
// The block spans from that candle's extreme inward by min(candle range,
// ATR(200)). Lifecycle from the creation bar on: mitigation by the candle
// BODY beyond the far edge (Close), the wick beyond it (Wick) or the body
// beyond the midpoint (Average); breakers off = removed, on = lives on as a
// breaker until a close crosses the near edge. Within = close inside any
// tracked block (either phase, inclusive). Entered = wick overlap now and not
// on the previous bar (order-block phase only).
// Readout volume in compact form: K / M / B with up to three decimals
// (10.973K, 44.38K, 4.01K), plain below a thousand.
func obFmtVol(v) {
  if (v >= 1000000000) { return tostring(round(v / 1000000) / 1000) + "B"; }
  if (v >= 1000000) { return tostring(round(v / 1000) / 1000) + "M"; }
  if (v >= 1000) { return tostring(round(v) / 1000) + "K"; }
  return tostring(round(v * 10) / 10);
}

// armed break level per side + the source-candle window it seeds
persist obHiArmed = false; persist obHiVal = 0;
persist obHiSrcLow = 0; persist obHiSrcHigh = 0; persist obHiSrcT = 0; persist obHiSrcBar = 0; persist obHiVol = 0; persist obHiBuy = 0;
persist obLoArmed = false; persist obLoVal = 0;
persist obLoSrcHigh = 0; persist obLoSrcLow = 0; persist obLoSrcT = 0; persist obLoSrcBar = 0; persist obLoVol = 0; persist obLoBuy = 0;

// tracked blocks (order-block or breaker phase): parallel arrays, newest last
persist obSide = [];      // 1 bullish, -1 bearish
persist obBot = [];       // box bottom
persist obTop = [];       // box top
persist obPhase = [];     // 0 order block, 1 breaker
persist obPrevTouch = []; // wick overlapped the block on the previous bar
persist obSrcT = [];      // source candle time (box left edge)
persist obSrcBar = [];    // source candle bar index (activity-bar arithmetic)
persist obBrkT = [];      // conversion bar time once a breaker (0 before)
persist obVol = [];       // leg volume (ours)
persist obBuyVol = [];    // leg up-candle volume (ours)
persist obDrawn = [];     // 1 while this block owns drawings
persist obBoxH = [];      // body box handle slot (frozen at the conversion bar once a breaker)
persist obBrkH = [];      // breaker segment box handle slot (from the conversion bar on)
persist obBrkOn = [];     // 1 while the breaker segment exists
persist obCapH = [];      // origin-cap box handle slot (the source candle's span; optional)
persist obBuyH = [];      // buy-activity bar handle slot
persist obSellH = [];     // sell-activity bar handle slot
persist obActH = [];      // 1 while the activity bars exist
persist obMidH = [];      // mid-line handle slot
persist obTagH = [];      // metrics tag handle slot
persist obTagTxt = [];    // metrics tag text (refreshed only when it changes)
persist obDrawnTotal = 0; // blocks currently owning drawings
persist obWinVolPrev = 0; // last bar's kept-window volume (the readout denominator)
// display constants: mid-line / tag end past the current bar (bars), origin
// cap alpha (percent)
var obMidExt = 1;
var obCapAlpha = min(90, obOpacity + 40);

// One block's drawing slots in the parallel arrays.
func obPushSlots() {
  obDrawn.push(0); obBoxH.push(na); obBrkH.push(na); obBrkOn.push(0); obCapH.push(na); obBuyH.push(na); obSellH.push(na); obActH.push(0);
  obMidH.push(na); obTagH.push(na); obTagTxt.push("");
}
func obRemoveAt(q) {
  obSide.removeAt(q); obBot.removeAt(q); obTop.removeAt(q); obPhase.removeAt(q);
  obPrevTouch.removeAt(q); obSrcT.removeAt(q); obSrcBar.removeAt(q); obBrkT.removeAt(q); obVol.removeAt(q); obBuyVol.removeAt(q);
  obDrawn.removeAt(q); obBoxH.removeAt(q); obBrkH.removeAt(q); obBrkOn.removeAt(q); obCapH.removeAt(q); obBuyH.removeAt(q); obSellH.removeAt(q); obActH.removeAt(q);
  obMidH.removeAt(q); obTagH.removeAt(q); obTagTxt.removeAt(q);
}
// Delete every drawing a block owns.
func obDropDrawings(q) {
  obBoxH[q].delete();
  if (obBrkOn[q] == 1) { obBrkH[q].delete(); obBrkOn[q] = 0; }
  if (obShowOriginCap) { obCapH[q].delete(); }
  if (obActH[q] == 1) { obBuyH[q].delete(); obSellH[q].delete(); obActH[q] = 0; }
  if (obShowMid) { obMidH[q].delete(); }
  if (obShowMetrics) { obTagH[q].delete(); }
  obDrawn[q] = 0;
  obDrawnTotal = obDrawnTotal - 1;
}
// Right end of an activity bar: its share of the block's age in bars (origin
// to the current bar inclusive), never left of the origin. A bar index past
// the current bar is extrapolated at the chart interval.
func obActEnd(srcBar, share) {
  var actLen = round(share * (barNo - srcBar + 1));
  if (actLen < 0) { actLen = 0; }
  var endBar = srcBar + actLen;
  if (endBar <= barNo) { return tHist[endBar]; }
  return d.time[0] + (endBar - barNo) * currentInterval;
}

// per-bar event flags (the alert streams) + pin values
var obBullCreated = false; var obBearCreated = false;
var obBullMitigated = false; var obBearMitigated = false;
var obBullBreaker = false; var obBearBreaker = false;
var obWithinBull = false; var obWithinBear = false;
var obBullEntered = false; var obBearEntered = false;
var obBullPin = na; var obBearPin = na;
var obBullCross = na; var obBearCross = na;

if (obShow) {
  // ------------------------------------------------- arming (from the detector)
  if (obEvt == 1) {
    // swing HIGH at the pivot bar (offset Length): arm the bullish break
    obHiArmed = true; obHiVal = d.high[obLength];
    obHiSrcLow = d.low[obLength - 1]; obHiSrcHigh = d.high[obLength - 1]; obHiSrcT = d.time[obLength - 1]; obHiSrcBar = barNo - (obLength - 1);
    obHiVol = d.volume[obLength - 1];
    obHiBuy = d.close[obLength - 1] >= d.open[obLength - 1] ? d.volume[obLength - 1] : 0;
    for (var ka = obLength - 2; ka >= 1; ka = ka - 1) {
      if (d.low[ka] < obHiSrcLow) { obHiSrcLow = d.low[ka]; obHiSrcHigh = d.high[ka]; obHiSrcT = d.time[ka]; obHiSrcBar = barNo - ka; }
      obHiVol = obHiVol + d.volume[ka];
      if (d.close[ka] >= d.open[ka]) { obHiBuy = obHiBuy + d.volume[ka]; }
    }
  }
  if (obEvt == 2) {
    // swing LOW at the pivot bar: arm the bearish break
    obLoArmed = true; obLoVal = d.low[obLength];
    obLoSrcHigh = d.high[obLength - 1]; obLoSrcLow = d.low[obLength - 1]; obLoSrcT = d.time[obLength - 1]; obLoSrcBar = barNo - (obLength - 1);
    obLoVol = d.volume[obLength - 1];
    obLoBuy = d.close[obLength - 1] >= d.open[obLength - 1] ? d.volume[obLength - 1] : 0;
    for (var kb = obLength - 2; kb >= 1; kb = kb - 1) {
      if (d.high[kb] > obLoSrcHigh) { obLoSrcHigh = d.high[kb]; obLoSrcLow = d.low[kb]; obLoSrcT = d.time[kb]; obLoSrcBar = barNo - kb; }
      obLoVol = obLoVol + d.volume[kb];
      if (d.close[kb] >= d.open[kb]) { obLoBuy = obLoBuy + d.volume[kb]; }
    }
  }

  // ---------------------------------------------------------- creation ----
  if (obHiArmed && d.close[0] > obHiVal) {
    obHiArmed = false;
    var obWb = min(obHiSrcHigh - obHiSrcLow, atr200);
    var obTopB = obHiSrcLow + obWb;
    obSide.push(1); obBot.push(obHiSrcLow); obTop.push(obTopB); obPhase.push(0);
    obPrevTouch.push(barNo > 0 && d.low[1] < obTopB && d.high[1] > obHiSrcLow);
    obSrcT.push(obHiSrcT); obSrcBar.push(obHiSrcBar); obBrkT.push(0); obVol.push(obHiVol); obBuyVol.push(obHiBuy);
    obPushSlots();
    obBullCreated = true;
    obBullPin = obHiSrcLow;
  }
  if (obLoArmed && d.close[0] < obLoVal) {
    obLoArmed = false;
    var obWs = min(obLoSrcHigh - obLoSrcLow, atr200);
    var obBotS = obLoSrcHigh - obWs;
    obSide.push(-1); obBot.push(obBotS); obTop.push(obLoSrcHigh); obPhase.push(0);
    obPrevTouch.push(barNo > 0 && d.low[1] < obLoSrcHigh && d.high[1] > obBotS);
    obSrcT.push(obLoSrcT); obSrcBar.push(obLoSrcBar); obBrkT.push(0); obVol.push(obLoVol); obBuyVol.push(obLoBuy);
    obPushSlots();
    obBearCreated = true;
    obBearPin = obLoSrcHigh;
  }

  // The source-candle window keeps growing while a level stays armed (this
  // bar joins it only after the break test above).
  if (obHiArmed) {
    if (d.low[0] < obHiSrcLow) { obHiSrcLow = d.low[0]; obHiSrcHigh = d.high[0]; obHiSrcT = d.time[0]; obHiSrcBar = barNo; }
    obHiVol = obHiVol + d.volume[0];
    if (d.close[0] >= d.open[0]) { obHiBuy = obHiBuy + d.volume[0]; }
  }
  if (obLoArmed) {
    if (d.high[0] > obLoSrcHigh) { obLoSrcHigh = d.high[0]; obLoSrcLow = d.low[0]; obLoSrcT = d.time[0]; obLoSrcBar = barNo; }
    obLoVol = obLoVol + d.volume[0];
    if (d.close[0] >= d.open[0]) { obLoBuy = obLoBuy + d.volume[0]; }
  }

  // --------------------------------------------------------- lifecycle ----
  // Every tracked block, newest first, the creation bar included.
  var obBodyLo = min(d.open[0], d.close[0]);
  var obBodyHi = max(d.open[0], d.close[0]);
  for (var obQ = obSide.length - 1; obQ >= 0; obQ = obQ - 1) {
    var qBull = obSide[obQ] == 1;
    var qBot = obBot[obQ];
    var qTop = obTop[obQ];
    var qTouch = d.low[0] < qTop && d.high[0] > qBot;
    var qRemove = false;
    if (obPhase[obQ] == 0) {
      var qMid = (qBot + qTop) / 2;
      var qDead = false;
      if (obMitigation == "Wick") {
        qDead = qBull ? d.low[0] < qBot : d.high[0] > qTop;
      } else {
        if (obMitigation == "Average") {
          qDead = qBull ? obBodyLo < qMid : obBodyHi > qMid;
        } else {
          qDead = qBull ? obBodyLo < qBot : obBodyHi > qTop;
        }
      }
      if (qTouch && obPrevTouch[obQ] == false) {
        if (qBull) { obBullEntered = true; } else { obBearEntered = true; }
      }
      if (qDead) {
        if (obShowBreakers) {
          obPhase[obQ] = 1;
          obBrkT[obQ] = d.time[0];
          if (qBull) { obBullBreaker = true; obBullCross = qMid; } else { obBearBreaker = true; obBearCross = qMid; }
          if (obDrawn[obQ] == 1) {
            // split at the mitigation bar: the block body freezes here and a
            // hollow dashed breaker segment carries on; faint cap, recolored
            // mid-line and tag
            var qBrkColor = qBull ? obBullBrkColor : obBearBrkColor;
            obBoxH[obQ].set_rightbottom(d.time[0], qBot);
            obBrkH[obQ] = box.new(d.time[0], qTop, d.time[0], qBot,
              {bgcolor: "transparent", borderColor: opacity(qBrkColor, 80), borderWidth: 1, borderStyle: "dashed",
               tooltip: qBull ? "Bullish breaker block" : "Bearish breaker block"});
            obBrkOn[obQ] = 1;
            if (obShowOriginCap) { obCapH[obQ].set_bgcolor(opacity(qBrkColor, obCapAlpha / 2)); }
            if (obShowMid) { obMidH[obQ].set_color(opacity(qBrkColor, 70)); }
            if (obShowMetrics) { obTagH[obQ].set_color(qBrkColor); }
          }
        } else {
          if (qBull) { obBullMitigated = true; } else { obBearMitigated = true; }
          qRemove = true;
        }
      }
    }
    if (qRemove == false && obPhase[obQ] == 1) {
      var qDie = qBull ? d.close[0] > qTop : d.close[0] < qBot;
      if (qDie) {
        if (qBull) { obBullMitigated = true; } else { obBearMitigated = true; }
        qRemove = true;
      }
    }
    if (qRemove) {
      if (obDrawn[obQ] == 1) { obDropDrawings(obQ); }
      obRemoveAt(obQ);
      continue;
    }
    if (d.close[0] >= qBot && d.close[0] <= qTop) {
      if (qBull) { obWithinBull = true; } else { obWithinBear = true; }
    }
    obPrevTouch[obQ] = qTouch;
  }

  // Safety valve: blocks are tracked without a cap (84 alive at once has
  // happened in testing); beyond 400 the oldest is dropped so a
  // pathological feed cannot grow state forever.
  if (obSide.length > 400) {
    if (obDrawn[0] == 1) { obDropDrawings(0); }
    obRemoveAt(0);
  }

  // -------------------------------------------------------------- view ----
  // Only the newest N (Blocks kept on chart) over BOTH sides own drawings
  // (body box, breaker segment once converted, buy / sell split bars,
  // optional source-candle highlight, midpoint line, readout). A block loses
  // its drawings the bar it leaves that window or dies, and regains them if
  // it re-enters. Skip overlapping blocks suppresses a block overlapping a
  // more recent drawn block of EITHER side (the most recent block wins; a
  // filled block living on as a breaker hides under a newer block it
  // overlaps the same way) without refilling the slot. The readout share is
  // taken over the whole kept window, skipped blocks included. Drawings are
  // created once and only
  // mutated on a phase change, when the window's volume changes, and on the
  // last bar (right edges follow price there).
  var obSeen = 0;
  var obWinVol = 0;
  var obDispBot = []; var obDispTop = [];
  var obDrawnIdx = [];
  var obSeenDrawn = 0;
  var obDrawnAtStart = obDrawnTotal;
  for (var obV = obSide.length - 1; obV >= 0; obV = obV - 1) {
    if (obSeen >= obShowLast && obSeenDrawn >= obDrawnAtStart) { break; }
    var vBull = obSide[obV] == 1;
    var vWasDrawn = obDrawn[obV] == 1;
    if (vWasDrawn) { obSeenDrawn = obSeenDrawn + 1; }
    var vShow = false;
    if (obSeen < obShowLast) {
      obSeen = obSeen + 1;
      obWinVol = obWinVol + obVol[obV];
      vShow = true;
      if (obHideOverlap) {
        for (var obOa = 0; obOa < obDispBot.length; obOa = obOa + 1) {
          if (obBot[obV] <= obDispTop[obOa] && obTop[obV] >= obDispBot[obOa]) { vShow = false; }
        }
      }
      if (vShow) { obDispBot.push(obBot[obV]); obDispTop.push(obTop[obV]); }
    }
    if (vShow) {
      obDrawnIdx.push(obV);
      if (vWasDrawn == false) {
        var vIsBrk = obPhase[obV] == 1;
        var vColor = vBull ? obBullColor : obBearColor;
        var vBrkColor = vBull ? obBullBrkColor : obBearBrkColor;
        var vLineColor = vIsBrk ? vBrkColor : vColor;
        var vTop = obTop[obV]; var vBot = obBot[obV];
        var vMid = (vTop + vBot) / 2;
        var vSrcT = obSrcT[obV];
        var vExtT = d.time[0] + obMidExt * currentInterval;
        // body: translucent fill, faint solid border; frozen at the
        // conversion bar once the block is a breaker
        obBoxH[obV] = box.new(vSrcT, vTop, vIsBrk ? obBrkT[obV] : d.time[0], vBot,
          {bgcolor: opacity(vColor, obOpacity), borderColor: opacity(vColor, 45), borderWidth: 1, borderStyle: "solid",
           tooltip: vBull ? "Bullish order block" : "Bearish order block"});
        // breaker segment: hollow, dashed, from the conversion bar on
        if (vIsBrk) {
          obBrkH[obV] = box.new(obBrkT[obV], vTop, d.time[0], vBot,
            {bgcolor: "transparent", borderColor: opacity(vBrkColor, 80), borderWidth: 1, borderStyle: "dashed",
             tooltip: vBull ? "Bullish breaker block" : "Bearish breaker block"});
          obBrkOn[obV] = 1;
        }
        // source-candle highlight (optional): the source candle's span at a stronger tint
        if (obShowOriginCap) {
          obCapH[obV] = box.new(vSrcT, vTop, vSrcT + currentInterval, vBot,
            {bgcolor: opacity(vLineColor, vIsBrk ? obCapAlpha / 2 : obCapAlpha), borderColor: "transparent", borderWidth: 1, borderStyle: "solid"});
        }
        // activity: the buy share fills the upper half, the sell share the
        // lower half, both from the origin, each as long as its share of the
        // block's age
        if (obShowActivity && obVol[obV] > 0) {
          var vBuy = obBuyVol[obV] / obVol[obV];
          obBuyH[obV] = box.new(vSrcT, vTop, obActEnd(obSrcBar[obV], vBuy), vMid,
            {bgcolor: opacity(iBull, 50), borderColor: "transparent", borderWidth: 1, borderStyle: "solid",
             tooltip: "Buy activity: " + tostring(round(100 * vBuy)) + "% of the leg volume"});
          obSellH[obV] = box.new(vSrcT, vMid, obActEnd(obSrcBar[obV], 1 - vBuy), vBot,
            {bgcolor: opacity(iBear, 50), borderColor: "transparent", borderWidth: 1, borderStyle: "solid",
             tooltip: "Sell activity: " + tostring(round(100 * (1 - vBuy))) + "% of the leg volume"});
          obActH[obV] = 1;
        }
        // mid-line dashed from the origin to one bar past the current bar;
        // metrics tag left-anchored at its end
        if (obShowMid) {
          obMidH[obV] = line.new(vSrcT, vMid, vExtT, vMid, {color: opacity(vLineColor, 70), width: 1, style: "dashed"});
        }
        if (obShowMetrics) {
          obTagH[obV] = label.new(vExtT, vMid, "", {color: vLineColor, bgcolor: "transparent", size: obChipSize, stickyRight: true});
          obTagTxt[obV] = "";
        }
        obDrawn[obV] = 1;
        obDrawnTotal = obDrawnTotal + 1;
      }
    } else {
      if (vWasDrawn) { obDropDrawings(obV); }
    }
  }
  // Right edges follow the current bar (last bar only); readouts are
  // refreshed when the kept window's volume changes (their share term) and on
  // the last bar.
  var obWinChanged = obWinVol != obWinVolPrev;
  obWinVolPrev = obWinVol;
  if (isLastBar || (obWinChanged && obShowMetrics)) {
    for (var obM = 0; obM < obDrawnIdx.length; obM = obM + 1) {
      var mi = obDrawnIdx[obM];
      var mMid = (obBot[mi] + obTop[mi]) / 2;
      if (isLastBar) {
        var mExtT = d.time[0] + obMidExt * currentInterval;
        if (obBrkOn[mi] == 1) { obBrkH[mi].set_rightbottom(d.time[0], obBot[mi]); }
        else { obBoxH[mi].set_rightbottom(d.time[0], obBot[mi]); }
        if (obActH[mi] == 1) {
          var mBuy = obBuyVol[mi] / obVol[mi];
          obBuyH[mi].set_rightbottom(obActEnd(obSrcBar[mi], mBuy), mMid);
          obSellH[mi].set_rightbottom(obActEnd(obSrcBar[mi], 1 - mBuy), obBot[mi]);
        }
        if (obShowMid) { obMidH[mi].set_xy2(mExtT, mMid); }
        if (obShowMetrics) { obTagH[mi].set_xy(mExtT, mMid); }
      }
      if (obShowMetrics) {
        var mShare = obWinVol > 0 ? round(100 * obVol[mi] / obWinVol) : 0;
        var mText = obFmtVol(obVol[mi]) + " (" + tostring(mShare) + "%)";
        if (mText != obTagTxt[mi]) { obTagH[mi].set_text(mText); obTagTxt[mi] = mText; }
      }
    }
  }

  // Creation pins (Event dots and pins): a small square at the far edge of the new
  // block on its creation (break) bar; conversion crosses at the block
  // midpoint on the bar it turns into a breaker. Series plots: no drawing cost.
  if (showEventMarkers) {
    plotShape(value=obBullPin, shape="square", colors=[obBullColor], width=5, location="absolute", fill=true,
      label=["Bullish block pin"], desc=["Creation pin: close broke the armed swing high; the square sits on the new block's bottom edge."]);
    plotShape(value=obBearPin, shape="square", colors=[obBearColor], width=5, location="absolute", fill=true,
      label=["Bearish block pin"], desc=["Creation pin: close broke the armed swing low; the square sits on the new block's top edge."]);
    plotShape(value=obBullCross, shape="cross", colors=[obBullBrkColor], width=6, location="absolute",
      label=["Bullish breaker cross"], desc=["Conversion cross: a bullish order block was mitigated and lives on as a breaker."]);
    plotShape(value=obBearCross, shape="cross", colors=[obBearBrkColor], width=6, location="absolute",
      label=["Bearish breaker cross"], desc=["Conversion cross: a bearish order block was mitigated and lives on as a breaker."]);
  }
}

// ============================================================================
// IMBALANCES (FVG / VOLUME IMBALANCE / OPENING GAP)
// ============================================================================
// FVG: this bar's low strictly above the high from two bars ago AND the middle
// candle closed above that high (mirror for bearish); the area is the wick
// gap. Volume Imbalance: two adjacent candles whose bodies do not overlap
// while their wicks do; area = the body gap. Opening Gap: two adjacent
// candles whose wicks do not overlap at all; area = the body gap. Per bar
// every live area is tested first (Close = the candle BODY through the far
// edge, Wick = wick through it, Average = body through the midpoint, None =
// never), mitigated areas pulse and are removed, then this bar's detection is
// inserted. The buffer keeps the newest 200 areas.
type ImbArea {
  top: number,
  bottom: number,
  side: number,
  bornT: number
}
func imbMitigated(mode, side, top, bottom, bLo, bHi, lo, hi) {
  if (mode == "None") { return false; }
  if (mode == "Close") {
    if (side == 1) { return bLo < bottom; }
    return bHi > top;
  }
  if (mode == "Wick") {
    if (side == 1) { return lo < bottom; }
    return hi > top;
  }
  var mid = (top + bottom) / 2;
  if (side == 1) { return bLo < mid; }
  return bHi > mid;
}

var bodyLo0 = min(d.open[0], d.close[0]);
var bodyHi0 = max(d.open[0], d.close[0]);
var bodyLo1 = 0;
var bodyHi1 = 0;
if (barNo > 0) {
  bodyLo1 = min(d.open[1], d.close[1]);
  bodyHi1 = max(d.open[1], d.close[1]);
}
var detSide = 0;
var detTop = 0;
var detBottom = 0;
var detLeftT = 0;
if (imbalanceType == "FVG") {
  if (barNo >= 2) {
    if (d.low[0] > d.high[2] && d.close[1] > d.high[2]) {
      detSide = 1; detTop = d.low[0]; detBottom = d.high[2]; detLeftT = d.time[2];
    } else {
      if (d.high[0] < d.low[2] && d.close[1] < d.low[2]) {
        detSide = -1; detTop = d.low[2]; detBottom = d.high[0]; detLeftT = d.time[2];
      }
    }
  }
}
if (imbalanceType == "Volume Imbalance") {
  if (barNo >= 1) {
    if (d.high[1] < bodyLo0 && d.low[0] < d.high[1]) {
      detSide = 1; detTop = bodyLo0; detBottom = bodyHi1; detLeftT = d.time[1];
    } else {
      if (d.high[0] < bodyLo1 && d.low[1] < d.high[0]) {
        detSide = -1; detTop = bodyLo1; detBottom = bodyHi0; detLeftT = d.time[1];
      }
    }
  }
}
if (imbalanceType == "Opening Gap") {
  if (barNo >= 1) {
    if (d.low[0] > d.high[1]) {
      detSide = 1; detTop = bodyLo0; detBottom = bodyHi1; detLeftT = d.time[1];
    } else {
      if (d.high[0] < d.low[1]) {
        detSide = -1; detTop = bodyLo1; detBottom = bodyHi0; detLeftT = d.time[1];
      }
    }
  }
}
var detKeep = detSide != 0 && (imbThreshold <= 0 || (detTop - detBottom) > imbThreshold * atr200);

// imbLive holds the area records, imbBoxes the matching box handles at the
// same index (a struct field cannot hold a drawing handle), imbMids the
// mid-line handles with imbMidOn flagging which areas carry one: the newest
// imbMidCap live areas do (the line budget is shared by every feature).
// Newest last.
persist imbLive = [];
persist imbBoxes = [];
persist imbMids = [];
persist imbMidOn = [];
persist imbMidCount = 0;
var imbMidCap = 120;
// Remove the area at k with its drawings.
func imbDropAt(k) {
  imbBoxes[k].delete();
  if (imbMidOn[k] == 1) { imbMids[k].delete(); imbMidCount = imbMidCount - 1; }
  imbBoxes.removeAt(k); imbMids.removeAt(k); imbMidOn.removeAt(k); imbLive.removeAt(k);
}
var newBullImb = false;
var newBearImb = false;
var mitBullImb = false;
var mitBearImb = false;
var mitBullLvl = na;
var mitBearLvl = na;
// Order Flow: a fill on flow in the fill's direction (a bullish gap is filled
// from above, on selling; a bearish gap from below, on buying)
var ofFillBullFlow = false; var ofFillBearFlow = false;
var imbTypeWord = imbalanceType == "FVG" ? "FVG" : (imbalanceType == "Volume Imbalance" ? "volume imbalance" : "opening gap");

if (showImbalances) {
  // 1. sweep the live buffer: test, pulse, remove (newest first so removal
  //    never disturbs the indices still to be visited)
  for (var imbK = imbLive.length - 1; imbK >= 0; imbK = imbK - 1) {
    var imbA = imbLive[imbK];
    if (imbMitigated(imbMitigation, imbA.side, imbA.top, imbA.bottom, bodyLo0, bodyHi0, d.low[0], d.high[0])) {
      if (imbA.side == 1) { mitBullImb = true; mitBullLvl = imbA.bottom; } else { mitBearImb = true; mitBearLvl = imbA.top; }
      imbDropAt(imbK);
    }
  }
  // 2. insert this bar's detection. A same-bar mitigation (possible only in
  //    Wick mode, on a Volume Imbalance whose upper wick dips below the lower
  //    body) pulses both events and never enters the buffer.
  if (detKeep) {
    if (detSide == 1) { newBullImb = true; } else { newBearImb = true; }
    if (imbMitigated(imbMitigation, detSide, detTop, detBottom, bodyLo0, bodyHi0, d.low[0], d.high[0])) {
      if (detSide == 1) { mitBullImb = true; mitBullLvl = detBottom; } else { mitBearImb = true; mitBearLvl = detTop; }
    } else {
      var imbColor = detSide == 1 ? imbBullColor : imbBearColor;
      imbLive.push(ImbArea.new(top=detTop, bottom=detBottom, side=detSide, bornT=detLeftT));
      var imbRightT = d.time[0] + imbExtend * currentInterval;
      // thin translucent box: faint fill, fainter solid edge, extended right;
      // graded by the volume shelf when the ladder is there: fast fill = dashed
      // edge, sticky = stronger fill, both with the numbers in the tooltip
      var gapGrade = ofGapVerdict(detBottom, detTop);
      if (gapGrade == 0) {
        imbBoxes.push(box.new(detLeftT, detTop, imbRightT, detBottom,
          {bgcolor: opacity(imbColor, 16), borderColor: opacity(imbColor, 40), borderWidth: 1, borderStyle: "solid"}));
      } else {
        var gapTip = (detSide == 1 ? "Bullish " : "Bearish ") + imbTypeWord + (gapGrade == 1 ? ": fast fill, thin shelf (" : ": sticky, high-volume node (") + "heaviest cell " + tostring(round(100 * gapTipMax / gapTipTypical) / 100) + " x typical)";
        if (gapGrade == 1) {
          imbBoxes.push(box.new(detLeftT, detTop, imbRightT, detBottom,
            {bgcolor: opacity(imbColor, 16), borderColor: opacity(imbColor, 55), borderWidth: 1, borderStyle: "dashed", tooltip: gapTip}));
        } else {
          imbBoxes.push(box.new(detLeftT, detTop, imbRightT, detBottom,
            {bgcolor: opacity(imbColor, 28), borderColor: opacity(imbColor, 60), borderWidth: 1, borderStyle: "solid", tooltip: gapTip}));
        }
      }
      // dashed mid-line at the area's average level, spanning the box; the
      // oldest mid-line gives way when the newest imbMidCap already carry one
      if (imbMidCount >= imbMidCap) {
        for (var imbO = 0; imbO < imbMidOn.length; imbO = imbO + 1) {
          if (imbMidOn[imbO] == 1) { imbMids[imbO].delete(); imbMidOn[imbO] = 0; imbMidCount = imbMidCount - 1; break; }
        }
      }
      var imbMidLvl = (detTop + detBottom) / 2;
      imbMids.push(line.new(detLeftT, imbMidLvl, imbRightT, imbMidLvl, {color: opacity(imbColor, 60), width: 1, style: "dashed"}));
      imbMidOn.push(1);
      imbMidCount = imbMidCount + 1;
      // Buffer: newest 200 areas, oldest discarded silently (no pulse).
      if (imbLive.length > 200) { imbDropAt(0); }
    }
  }
  // Order Flow: the fill's direction against the bar's delta share
  ofFillBullFlow = ofGapGrade && mitBullImb && ofHasFlow && ofShare <= 0 - ofThr;
  ofFillBearFlow = ofGapGrade && mitBearImb && ofHasFlow && ofShare >= ofThr;
  // Fill marks (off by default): a cross at the breached edge on the bar
  // that did it (a series plot, so it costs no drawings); with the grades on,
  // a fill on flow in its direction adds a larger x-cross.
  if (imbShowMitigation) {
    plotShape(value=mitBullLvl, shape="cross", location="absolute", colors=[imbBullColor], width=6,
      label=["Bullish gap fill mark"],
      desc=["Cross at the bottom edge of a bullish imbalance on the bar that mitigated it."]);
    plotShape(value=mitBearLvl, shape="cross", location="absolute", colors=[imbBearColor], width=6,
      label=["Bearish gap fill mark"],
      desc=["Cross at the top edge of a bearish imbalance on the bar that mitigated it."]);
    if (ofGapGrade) {
      plotShape(value=ofFillBullFlow ? mitBullLvl : na, shape="xcross", location="absolute", colors=[opacity(imbBullColor, 85)], width=8,
        label=["Bullish gap filled on selling"],
        desc=["A bullish imbalance filled on a bar whose delta share was net selling beyond the participation threshold."]);
      plotShape(value=ofFillBearFlow ? mitBearLvl : na, shape="xcross", location="absolute", colors=[opacity(imbBearColor, 85)], width=8,
        label=["Bearish gap filled on buying"],
        desc=["A bearish imbalance filled on a bar whose delta share was net buying beyond the participation threshold."]);
    }
  }
}

// ============================================================================
// LIQUIDITY TREND LINES + CHART PATTERNS
// ============================================================================
// Trend lines: wick pivots two bars either side (left ties allowed, right
// strict) confirm two bars late. A pivot low that made a LOWER low than the
// pivot low before it becomes the bullish anchor; a later pivot low that
// makes a HIGHER low is a candidate end. The segment is a support trend line
// when no close between them fell below it and at least one wick did. Same
// anchor as the live line: re-fit (update); otherwise a new line replaces the
// live one. Bearish mirrors this on pivot highs. A line is broken by the
// first close beyond it; the test is skipped on same-side pivot-confirm bars,
// and each such bar that fires no event lags the projected line by one bar.
// One live line per side, one break per line, an update re-arms. Zone =
// 0.25 x ATR(200) at the confirm bar.
//
// Patterns: symmetric body pivots (half-length 2 x Period) merged into an
// alternating zigzag; the last four swings give the upper line (two highs)
// and the lower line (two lows). Flat = |slope| < 0.25 x |other|: flat
// bottom + falling top = Descending Triangle, flat top + rising bottom =
// Ascending Triangle; sU < 0 < sL = Symmetrical Triangle; megaphone = None;
// same sign: width ratio < 2/3 = wedge, > 3/2 (or a negative first width) =
// broadening wedge, else None. Converging patterns draw to the rounded apex,
// diverging ones from it, None runs both lines to the current bar as general
// S/R. Zone = 0.5 x ATR(200) at the current bar. Double Top / Double Bottom
// and Head & Shoulders are NOT emitted (no rule survived the data).
var lpActive = tlShow || patShow;
persist hT = [];
persist hH = [];
persist hL = [];
persist hC = [];
persist barMs = 0;
if (lpActive) {
  hT.push(d.time[0]);
  hH.push(d.high[0]);
  hL.push(d.low[0]);
  hC.push(d.close[0]);
  if (barNo > 0) {
    var stepMs = hT[barNo] - hT[barNo - 1];
    if (stepMs > 0 && (barMs == 0 || stepMs < barMs)) { barMs = stepMs; }
  }
}
// bar index -> time, extrapolated past either end of the history
func lpTimeAt(x) {
  if (x >= 0 && x < hT.length) { return hT[x]; }
  return hT[barNo] + (x - barNo) * barMs;
}

// ------------------------------------------------------------ trend lines ----
// Per-side state, index 0 = support (pivot lows), 1 = resistance (pivot highs).
persist tlHavePrev = [false, false];
persist tlPrevPrice = [0, 0];
persist tlAnchorBar = [-1, -1];
persist tlAnchorPrice = [0, 0];
persist tlHas = [false, false];
persist tlA = [0, 0];
persist tlAPrice = [0, 0];
persist tlSlope = [0, 0];
persist tlC = [0, 0];
persist tlLag = [0, 0];
persist tlBroken = [false, false];
persist tlWidth = [0, 0];
// drawing holders (newest last; index-aligned main / zone edge / fill). No
// text: the line's color and slope say which side it is.
persist tlBullMain = [];
persist tlBullEdge = [];
persist tlBullFill = [];
persist tlBearMain = [];
persist tlBearEdge = [];
persist tlBearFill = [];
// Break tails: a broken line keeps a three-bar tail past the break, drawn on
// the three real bars after it as they close from the line frozen at the
// break. Tails live in one FIFO queue keyed by group id so an update
// re-fitting that group or an eviction cancels the tail.
persist tlGroupSeq = 0;
persist tlBullIds = [];
persist tlBearIds = [];
persist tlTailMain = [];
persist tlTailEdge = [];
persist tlTailId = [];
persist tlTailLeft = [];
persist tlTailBar = [];
persist tlTailY = [];
persist tlTailSlope = [];
persist tlTailOff = [];

// per-bar event flags (alerts + markers)
var tlNewBull = false;
var tlNewBear = false;
var tlUpdBull = false;
var tlUpdBear = false;
var tlBrkBull = false;
var tlBrkBear = false;
var tlBrkBullY = na;
var tlBrkBearY = na;

func tlLineAt(s, x) {
  return tlAPrice[s] + tlSlope[s] * (x - tlA[s]);
}
func tlZoneOffset(s) {
  return s == 0 ? tlWidth[s] : -tlWidth[s];
}
func tlHasDrawing(s) {
  return s == 0 ? tlBullMain.length > 0 : tlBearMain.length > 0;
}
func tlSetEnd(s, x, y) {
  var off = tlZoneOffset(s);
  if (s == 0) {
    tlBullMain[tlBullMain.length - 1].set_xy2(x, y);
    tlBullEdge[tlBullEdge.length - 1].set_xy2(x, y + off);
  } else {
    tlBearMain[tlBearMain.length - 1].set_xy2(x, y);
    tlBearEdge[tlBearEdge.length - 1].set_xy2(x, y + off);
  }
}
func tlSetStart(s, x, y) {
  var off = tlZoneOffset(s);
  if (s == 0) {
    tlBullMain[tlBullMain.length - 1].set_xy1(x, y);
    tlBullEdge[tlBullEdge.length - 1].set_xy1(x, y + off);
  } else {
    tlBearMain[tlBearMain.length - 1].set_xy1(x, y);
    tlBearEdge[tlBearEdge.length - 1].set_xy1(x, y + off);
  }
}
func tlSetStyle(s, sty, w) {
  if (s == 0) {
    tlBullMain[tlBullMain.length - 1].set_style(sty);
    tlBullMain[tlBullMain.length - 1].set_width(w);
  } else {
    tlBearMain[tlBearMain.length - 1].set_style(sty);
    tlBearMain[tlBearMain.length - 1].set_width(w);
  }
}
func tlNewestId(s) {
  return s == 0 ? tlBullIds[tlBullIds.length - 1] : tlBearIds[tlBearIds.length - 1];
}
// cancel any pending tail on a group (its drawing was re-anchored or deleted)
func tlTailKill(id) {
  for (var q = 0; q < tlTailId.length; q = q + 1) {
    if (tlTailId[q] == id) { tlTailLeft[q] = 0; }
  }
}
// arm a three-bar tail on side s's newest group from the line frozen at the break
func tlTailArm(s, yBrk) {
  tlTailKill(tlNewestId(s));
  if (s == 0) {
    tlTailMain.push(tlBullMain[tlBullMain.length - 1]);
    tlTailEdge.push(tlBullEdge[tlBullEdge.length - 1]);
  } else {
    tlTailMain.push(tlBearMain[tlBearMain.length - 1]);
    tlTailEdge.push(tlBearEdge[tlBearEdge.length - 1]);
  }
  tlTailId.push(tlNewestId(s));
  tlTailLeft.push(3);
  tlTailBar.push(barNo);
  tlTailY.push(yBrk);
  tlTailSlope.push(tlSlope[s]);
  tlTailOff.push(tlZoneOffset(s));
}
// one bar of every live tail: its drawing ends on this (real) bar, on the
// frozen line. Tails finish in arm order (all are three bars), so finished
// and cancelled entries are retired from the head of the queue.
func tlTailStep() {
  for (var q = 0; q < tlTailId.length; q = q + 1) {
    if (tlTailLeft[q] > 0) {
      var y = tlTailY[q] + tlTailSlope[q] * (barNo - tlTailBar[q]);
      tlTailMain[q].set_xy2(hT[barNo], y);
      tlTailEdge[q].set_xy2(hT[barNo], y + tlTailOff[q]);
      tlTailLeft[q] = tlTailLeft[q] - 1;
    }
  }
  while (tlTailId.length > 0 && tlTailLeft[0] == 0) {
    tlTailMain.shift(); tlTailEdge.shift(); tlTailId.shift(); tlTailLeft.shift();
    tlTailBar.shift(); tlTailY.shift(); tlTailSlope.shift(); tlTailOff.shift();
  }
}
// Pruning rule: only the newest tlShowLast lines per side own drawings (main
// line + zone edge + fill); the oldest group is deleted when a new line
// arrives past the cap (a tail pending on it is dropped). An update re-fits
// the newest group in place.
func tlAddGroup(s, x1, y1, x2, y2) {
  var col = s == 0 ? tlBullColor : tlBearColor;
  var off = tlZoneOffset(s);
  if (s == 0) {
    if (tlBullMain.length >= tlShowLast) {
      tlTailKill(tlBullIds[0]);
      tlBullFill[0].delete(); tlBullMain[0].delete(); tlBullEdge[0].delete();
      tlBullFill.shift(); tlBullMain.shift(); tlBullEdge.shift(); tlBullIds.shift();
    }
  } else {
    if (tlBearMain.length >= tlShowLast) {
      tlTailKill(tlBearIds[0]);
      tlBearFill[0].delete(); tlBearMain[0].delete(); tlBearEdge[0].delete();
      tlBearFill.shift(); tlBearMain.shift(); tlBearEdge.shift(); tlBearIds.shift();
    }
  }
  // 2px main line, faint dotted zone edge, light fill (alpha 0..1 here)
  var main = line.new(x1, y1, x2, y2, {color: col, width: 2, style: "solid"});
  var edge = line.new(x1, y1 + off, x2, y2 + off, {color: opacity(col, 35), width: 1, style: "dotted"});
  var fill = linefill.new(main, edge, {color: col, opacity: 0.1});
  tlGroupSeq = tlGroupSeq + 1;
  if (s == 0) {
    tlBullMain.push(main); tlBullEdge.push(edge); tlBullFill.push(fill); tlBullIds.push(tlGroupSeq);
  } else {
    tlBearMain.push(main); tlBearEdge.push(edge); tlBearFill.push(fill); tlBearIds.push(tlGroupSeq);
  }
}

if (tlShow) {
  // pivot(2,2) on wicks, confirmed on this bar for the bar two back
  var pv = barNo - 2;
  var isPivotHigh = false;
  var isPivotLow = false;
  if (barNo >= 4) {
    isPivotHigh = hH[pv - 2] <= hH[pv] && hH[pv - 1] <= hH[pv] && hH[pv + 1] < hH[pv] && hH[pv + 2] < hH[pv];
    isPivotLow = hL[pv - 2] >= hL[pv] && hL[pv - 1] >= hL[pv] && hL[pv + 1] > hL[pv] && hL[pv + 2] > hL[pv];
  }
  tlTailStep();
  for (var s = 0; s < 2; s = s + 1) {
    var isBull = s == 0;
    var piv = isBull ? isPivotLow : isPivotHigh;
    var evented = false;
    if (piv) {
      var pPrice = isBull ? hL[pv] : hH[pv];
      var dPrev = tlHavePrev[s] ? (isBull ? pPrice - tlPrevPrice[s] : tlPrevPrice[s] - pPrice) : 0;
      var isDeeper = tlHavePrev[s] && dPrev < 0;
      if (!isDeeper && tlAnchorBar[s] >= 0 && (isBull ? pPrice > tlAnchorPrice[s] : pPrice < tlAnchorPrice[s])) {
        // candidate line anchor -> this pivot: gate on closes and wicks in between
        var A = tlAnchorBar[s];
        var slope = (pPrice - tlAnchorPrice[s]) / (pv - A);
        var closesBeyond = 0;
        var wicksBeyond = 0;
        for (var u = A + 1; u < pv; u = u + 1) {
          var lv = tlAnchorPrice[s] + slope * (u - A);
          if (isBull ? hC[u] < lv : hC[u] > lv) { closesBeyond = closesBeyond + 1; }
          if (isBull ? hL[u] < lv : hH[u] > lv) { wicksBeyond = wicksBeyond + 1; }
        }
        if (closesBeyond == 0 && wicksBeyond >= 1) {
          var isUpd = tlHas[s] && tlA[s] == A;
          // a new line retires the live one: its drawing ends on the previous bar
          if (tlHas[s] && !isUpd && !tlBroken[s] && tlHasDrawing(s)) {
            tlSetEnd(s, hT[barNo - 1], tlLineAt(s, barNo - 1 - tlLag[s]));
          }
          tlHas[s] = true;
          tlA[s] = A;
          tlAPrice[s] = tlAnchorPrice[s];
          tlSlope[s] = slope;
          tlC[s] = barNo;
          tlLag[s] = 0;
          tlBroken[s] = false;
          tlWidth[s] = 0.25 * atr200;
          if (isBull) { if (isUpd) { tlUpdBull = true; } else { tlNewBull = true; } }
          else { if (isUpd) { tlUpdBear = true; } else { tlNewBear = true; } }
          evented = true;
          var yEnd = tlLineAt(s, barNo);
          if (isUpd && tlHasDrawing(s)) {
            tlTailKill(tlNewestId(s));
            tlSetStart(s, hT[A], tlAPrice[s]);
            tlSetEnd(s, hT[barNo], yEnd);
            tlSetStyle(s, "solid", 2);
          } else {
            tlAddGroup(s, hT[A], tlAPrice[s], hT[barNo], yEnd);
          }
        }
      }
      if (isDeeper) { tlAnchorBar[s] = pv; tlAnchorPrice[s] = pPrice; }
      tlHavePrev[s] = true;
      tlPrevPrice[s] = pPrice;
      if (tlHas[s] && !evented) { tlLag[s] = tlLag[s] + 1; }
    }
    if (tlHas[s] && !tlBroken[s] && barNo > tlC[s]) {
      var yNow = tlLineAt(s, barNo - tlLag[s]);
      if (!piv && (isBull ? d.close[0] < yNow : d.close[0] > yNow)) {
        // broken: the drawing turns dashed, ends on this bar and grows a
        // three-bar tail over the next three closed bars
        tlBroken[s] = true;
        if (isBull) { tlBrkBull = true; tlBrkBullY = yNow; } else { tlBrkBear = true; tlBrkBearY = yNow; }
        if (tlHasDrawing(s)) {
          tlSetEnd(s, hT[barNo], yNow);
          tlSetStyle(s, "dashed", 1);
          tlTailArm(s, yNow);
        }
      } else if (isLastBar && tlHasDrawing(s)) {
        // live line: extend to the current bar (drawn once, on the last bar)
        tlSetEnd(s, hT[barNo], yNow);
      }
    }
  }
}

// --------------------------------------------------------------- patterns ----
var patLen = 2 * tonumber(patPeriodSel);
persist bodyHi = [];
persist bodyLo = [];
persist zzKind = [];
persist zzBar = [];
persist zzPrice = [];
persist patName = "None";
persist patLines = [];
persist patEdges = [];
persist patFills = [];
var patChanged = false;

func zzPush(k, x, y) {
  var m = zzKind.length;
  if (m > 0 && zzKind[m - 1] == k) {
    if ((k == 1 && y > zzPrice[m - 1]) || (k == -1 && y < zzPrice[m - 1])) { zzBar[m - 1] = x; zzPrice[m - 1] = y; }
  } else {
    zzKind.push(k); zzBar.push(x); zzPrice.push(y);
    if (zzKind.length > 40) { zzKind.shift(); zzBar.shift(); zzPrice.shift(); }
  }
}

if (patShow) {
  bodyHi.push(math.max(d.open[0], d.close[0]));
  bodyLo.push(math.min(d.open[0], d.close[0]));
  // symmetric body pivots: left ties allowed, right strict; confirmed patLen bars late
  var cb = barNo - patLen;
  var bodyPH = false;
  var bodyPL = false;
  if (barNo >= 2 * patLen) {
    bodyPH = true;
    bodyPL = true;
    for (var j = cb - patLen; j < cb; j = j + 1) {
      if (bodyHi[j] > bodyHi[cb]) { bodyPH = false; }
      if (bodyLo[j] < bodyLo[cb]) { bodyPL = false; }
    }
    for (var j2 = cb + 1; j2 <= barNo; j2 = j2 + 1) {
      if (bodyHi[j2] >= bodyHi[cb]) { bodyPH = false; }
      if (bodyLo[j2] <= bodyLo[cb]) { bodyPL = false; }
    }
  }
  if (bodyPH) { zzPush(1, cb, bodyHi[cb]); }
  if (bodyPL) { zzPush(-1, cb, bodyLo[cb]); }

  var m4 = zzKind.length;
  if (m4 >= 4) {
    // last four swings: two highs and two lows in time order
    var hx1 = 0; var hy1 = 0; var hx2 = 0; var hy2 = 0;
    var lx1 = 0; var ly1 = 0; var lx2 = 0; var ly2 = 0;
    var nh = 0; var nl = 0;
    for (var patQ = m4 - 4; patQ < m4; patQ = patQ + 1) {
      if (zzKind[patQ] == 1) {
        if (nh == 0) { hx1 = zzBar[patQ]; hy1 = zzPrice[patQ]; } else { hx2 = zzBar[patQ]; hy2 = zzPrice[patQ]; }
        nh = nh + 1;
      } else {
        if (nl == 0) { lx1 = zzBar[patQ]; ly1 = zzPrice[patQ]; } else { lx2 = zzBar[patQ]; ly2 = zzPrice[patQ]; }
        nl = nl + 1;
      }
    }
    var sU = (hy2 - hy1) / (hx2 - hx1);
    var sL = (ly2 - ly1) / (lx2 - lx1);
    var firstBar = math.min(hx1, lx1);
    var lastBar = math.max(hx2, lx2);
    var w0 = (hy1 + sU * (firstBar - hx1)) - (ly1 + sL * (firstBar - lx1));
    var w1 = (hy1 + sU * (lastBar - hx1)) - (ly1 + sL * (lastBar - lx1));
    var aU = math.abs(sU);
    var aL = math.abs(sL);
    var flatTop = aU < 0.25 * aL;
    var flatBottom = aL < 0.25 * aU;
    var name = "None";
    if (flatBottom && sU < 0) { name = "Descending Triangle"; }
    else if (flatTop && sL > 0) { name = "Ascending Triangle"; }
    else if (sU < 0 && sL > 0) { name = "Symmetrical Triangle"; }
    else if (sU > 0 && sL < 0) { name = "None"; }
    else if (sU == 0 || sL == 0) { name = "None"; }
    else {
      var r = w1 / w0;
      if (w0 > 0 && r < 2 / 3) { name = sU < 0 ? "Falling Wedge" : "Rising Wedge"; }
      else if (w0 <= 0 || r > 1.5) { name = sU < 0 ? "Descending Broadening Wedge" : "Ascending Broadening Wedge"; }
      else { name = "None"; }
    }
    if (name != patName) { patChanged = true; }
    patName = name;

    if (isLastBar) {
      // geometry: converging -> to the apex, diverging -> from the apex,
      // None -> both lines to the current bar (general support / resistance)
      var isNone = name == "None";
      var apex = sU != sL ? ((ly1 - sL * lx1) - (hy1 - sU * hx1)) / (sU - sL) : 0;
      var apexBar = math.ceil(apex - 0.5);
      var x1 = firstBar;
      var x2 = barNo;
      if (!isNone && sU != sL) {
        if (sU < sL) { x2 = apexBar; } else { x1 = apexBar; }
      }
      var yU1 = hy1 + sU * (x1 - hx1);
      var yU2 = hy1 + sU * (x2 - hx1);
      var yL1 = ly1 + sL * (x1 - lx1);
      var yL2 = ly1 + sL * (x2 - lx1);
      var wz = 0.5 * atr200;
      var tx1 = lpTimeAt(x1);
      var tx2 = lpTimeAt(x2);
      var sty = isNone ? "dotted" : "solid";
      var wid = isNone ? 1 : 2;
      if (patLines.length == 0) {
        patLines.push(line.new(tx1, yU1, tx2, yU2, {color: patUpperColor, width: wid, style: sty}));
        patLines.push(line.new(tx1, yL1, tx2, yL2, {color: patLowerColor, width: wid, style: sty}));
        if (patShowZones) {
          patEdges.push(line.new(tx1, yU1 + wz, tx2, yU2 + wz, {color: opacity(patUpperColor, 35), width: 1, style: "dotted"}));
          patEdges.push(line.new(tx1, yL1 - wz, tx2, yL2 - wz, {color: opacity(patLowerColor, 35), width: 1, style: "dotted"}));
          patFills.push(linefill.new(patLines[0], patEdges[0], {color: patUpperColor, opacity: 0.1}));
          patFills.push(linefill.new(patLines[1], patEdges[1], {color: patLowerColor, opacity: 0.1}));
        }
      } else {
        patLines[0].set_xy1(tx1, yU1); patLines[0].set_xy2(tx2, yU2); patLines[0].set_style(sty); patLines[0].set_width(wid);
        patLines[1].set_xy1(tx1, yL1); patLines[1].set_xy2(tx2, yL2); patLines[1].set_style(sty); patLines[1].set_width(wid);
        if (patShowZones) {
          patEdges[0].set_xy1(tx1, yU1 + wz); patEdges[0].set_xy2(tx2, yU2 + wz);
          patEdges[1].set_xy1(tx1, yL1 - wz); patEdges[1].set_xy2(tx2, yL2 - wz);
        }
      }
    }
  }
}
