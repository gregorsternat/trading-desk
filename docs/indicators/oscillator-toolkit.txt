//@version=3
// Oscillator Toolkit
//
// One indicator, one pane, every oscillator feature a trader stacks: a momentum wave with its
// signal line and turn markers, wave divergences, a range-weighted money flow with adaptive
// ceilings / floors and surge shading, reversal flags (minor / major), and confluence strips
// with a confluence score, plus two order-flow lanes the candle-only tools cannot have: a taker
// money flow read from the venue's sided trade tape and CVD divergences. A user adds this one
// script and gets everything; each feature is a settings group with its own display toggle, and
// every feature evaluates on bar close.
//
// Everything is built on TWO primitives, computed once per bar and shared:
//
//   Momentum wave (+ signal). m = floor(sqrt(L)); mom = close - close[m];
//   wave = 50 + 50 * ema(ema(mom, L), L) / ema(ema(|mom|, L), L)  (L = wave smoothing, 7).
//   Signal = sma(wave, signalLength) or a trailing stop ON the wave (width = signalLength x
//   rma20(|change(wave)|), alpha fixed 1/20). Consumers: wave turns (wave/signal crosses graded
//   at 20/80), divergences (strict 1/1 fractal pivots on the wave), reversal grading (major iff
//   the wave sits beyond 80/20 on the firing bar), confluence (wave > 50, wave vs signal, 56/44
//   strength gates).
//
//   Range money flow (+ ceiling / floor, surge). g = sma(high - low, len); core = 100 x sum(up ?
//   g : 0, len) / sum(g, len) with ties counted as down; MF = ema(core, smooth). The ceiling and
//   floor are attack / release chasers (0.2 / 0.005) clamped at the 50 midline; a surge = MF
//   beyond its ceiling / floor, plotted as max(50, MF - 10) / min(50, MF + 10). Consumers: surge
//   episodes and surge-start alerts, confluence (mf > 50, surge element).
//
//   The reversal detector is pure price (proven independent of every oscillator knob): x =
//   (close - ref) / trueRange with ref = close of the last reversal either side; Down fires when
//   x > 0.5 x factor, Up when x < -0.5 x factor (strict, 1e-9 tie tolerance); on fire ref := close.
//   Grade "+" (major) iff the wave is beyond its extreme zone on the firing bar AND the previous
//   reversal was on the same side.
//
//   Order flow (additive lanes; buy_sell_volume in USD, fetched only while a lane is on). Taker
//   money flow = 50 + 50 x wma(buy - sell, n) / wma(buy + sell, n) on the pane's 0..100 frame
//   (50 = balanced aggression), its bands = nearest-rank 80th / 20th percentile of itself over the
//   last 100 bars (NaN while the window holds a NaN). CVD = session-anchored cumulative (buy -
//   sell); CVD divergences use the wave divergences' pivot rule on the CVD (strict 1/1 fractal
//   confirmed one bar later, lowest / highest CLOSE over the 6 bars ending at the pivot, the
//   previous same-side pivot as the comparison point, both pivots inside one session), grade "+" when the
//   persist-summed higher-frame CVD slope (delta summed over the last completed 4-bar bucket plus
//   the developing one, calendar-aligned) agrees. On venues without sided trades (US equities)
//   the source is empty: both lanes stay absent and the pane is the classic build.
//
// Original implementation. Every feature is covered by a deterministic test harness on two
// engine versions.
//
// Pane layout (one 0..100 frame with outer lanes). Four hues: teal / slate for the wave by its
// side of the signal, sky / rose for every other bullish / bearish element (money flow, surges,
// divergences, reversal flags, confluence), slate for the frame.
//   111 / -11      reversal lanes: small ring = minor, larger glowing dot = major
//   101..106       bullish confluence strip: a translucent sky strip whose height grades the state
//                  (none = nothing, weak = 3 units, strong = 5 units; a dotted inner edge and a
//                  solid outer edge that brightens with the state)
//   -1..-6         bearish confluence strip (rose)
//   0..100         wave 2px (teal / slate) with a dotted signal line and a translucent band
//                  between them; money flow 1px (sky / rose by its side of 50) with one dotted
//                  ceiling / floor visible per bar and surge shading between the surge front and
//                  the midline (its height IS the depth); dotted 20 / 50 / 80 guides; wave turns
//                  as small dots ON the wave (larger glowing dots from the oversold / overbought
//                  zones); divergence connectors (dashed 1px) between the two wave pivots and a
//                  small arrow in the pane-edge lane on the confirm bar; the confluence score
//                  (off by default) as a line with a translucent fill toward 50, optionally a
//                  score dial (110 one-unit gradient boxes + pointer right of the last bar)
//   price chart    divergence connectors (dashed 1px, pane "onchart") between the two extreme
//                  closes the detection compared; optional arrows under / over the confirm bar
//   order flow     taker money flow 1px (violet) with its two bands (violet, 40%) inside the frame;
//                  CVD divergence diamonds in their own lanes (-8.5 bullish / 108.5 bearish; full
//                  tone = "+" grade, 60% tone = base grade); optionally (off: validator visits) a
//                  connector on the price chart between the two extreme closes compared (solid
//                  1px "+", dashed base grade)
//
// Renderer facts the visuals rest on (titan-charts-next 0.0.4-alpha.698, both engines):
//   - fillBetween.opacity is the fill's alpha on a 0..1 scale (the engine clamps it to 0..1 and
//     the renderer replaces the color's own alpha with it); percent-scale values render fully
//     opaque. The renderer draws one polygon per run of bars sharing the fill's color AND opacity
//     and drops single-bar runs, so a fill whose color or alpha changes per bar tears at every
//     change: every fill here keeps a constant alpha and changes color only where its height is
//     zero (episode / side boundaries), and the confluence strips grade the state by height, not
//     by alpha.
//   - a fill only renders between two PLOTTED single-value series (refs resolve by plotKey), and
//     a plot whose colors are all fully transparent is dropped by the app as a helper, so every
//     fill base (midline, strip edges) is a real faint line.
//   - shape="circle" is plotType "point" (fill=false = ring); the grade of a marker rides its
//     width; shape="star" has no renderer (maps to diamond).
//
// Frontend budget (measured on engines 3.0.61 / 3.0.83 / 3.0.84, harness/budget.mjs): see
// README.md "Budget". Series 26 at defaults (24 classic + the taker flow 3-column plot + the CVD
// divergence markers, both absent without sided data), 30 with every toggle on (cap 32; 30 x
// 5,000 bars = the 150k row preflight exactly); rows = series x bars (every series output carries
// one row per bar, markers and fills included); drawings = divergence connectors (wave: FIFO 120
// per side per pane; CVD chart connectors, off by default: FIFO 60 per side and never past 490
// lines alive in total, engine cap 500 per kind) plus 111 dial boxes on the last bar when the
// dial is on. Validator visits: each alive line costs 2, each output ~9; the order-flow lanes add
// 28 at defaults (361 vs 333, +8%). Alerts are unconditional: every classic condition is recorded
// whether or not its feature is displayed, and the four order-flow conditions compute while either
// order-flow lane is on (the sided data is only fetched then); the app drops the alert ledger
// before its validator, so alert rows cost no validation visits.
define(title="Oscillator Toolkit", position="offchart", axis=true);

// ============================================================================
// SHARED MODEL (computed once per bar; every feature reads from here)
// ============================================================================

// ── Wave core: double-EMA normalized momentum, mapped to 0..100 ───────────────
var m = floor(sqrt(hwLen));
timeseries mo = d.close - d.close[m];
var aL = 2.0 / (hwLen + 1);

persist e1n = na;
persist e2n = na;
persist e1d = na;
persist e2d = na;
if (!isna(mo)) {
  var am = abs(mo);
  e1n = isna(e1n) ? mo : aL * mo + (1 - aL) * e1n;
  e1d = isna(e1d) ? am : aL * am + (1 - aL) * e1d;
  e2n = isna(e2n) ? e1n : aL * e1n + (1 - aL) * e2n;
  e2d = isna(e2d) ? e1d : aL * e1d + (1 - aL) * e2d;
}
var hwVal = isna(e2d) || e2d == 0 ? na : 50 + 50 * e2n / e2d;

// ── Signal companion: SMA of the wave, or a trailing stop ON the wave ──────────
persist smaWin = [];
var sigSmaVal = na;
if (isna(hwVal)) {
  while (smaWin.length > 0) { smaWin.pop(); }
} else {
  smaWin.push(hwVal);
  if (smaWin.length > sigLen) { smaWin.shift(); }
  if (smaWin.length == sigLen) {
    var acc = 0.0;
    for (var jS = 0; jS < smaWin.length; jS = jS + 1) { acc = acc + smaWin[jS]; }
    sigSmaVal = acc / sigLen;
  }
}

persist tsAvgMove = na;
persist tsStop = na;
persist tsDir = 0;
persist tsPrevWave = na;
if (!isna(hwVal)) {
  if (!isna(tsPrevWave)) {
    var dv = abs(hwVal - tsPrevWave);
    tsAvgMove = isna(tsAvgMove) ? dv : tsAvgMove + 0.05 * (dv - tsAvgMove);
  }
  if (!isna(tsAvgMove)) {
    var w = sigLen * tsAvgMove;
    if (tsDir == 0) {
      tsDir = 1;
      tsStop = hwVal - w;
    } else if (tsDir == 1) {
      if (hwVal < tsStop) {
        tsDir = -1;
        tsStop = hwVal + w;
      } else {
        tsStop = math.max(tsStop, hwVal - w);
      }
    } else {
      if (hwVal > tsStop) {
        tsDir = 1;
        tsStop = hwVal - w;
      } else {
        tsStop = math.min(tsStop, hwVal + w);
      }
    }
  }
  tsPrevWave = hwVal;
}

var sigVal = sigMode == "SMA" ? sigSmaVal : tsStop;

timeseries wave = hwVal;
timeseries sig = sigVal;

// ── Wave turns: one marker per wave/signal cross, graded at the extremes ───────
persist pWave = na;
persist pSig = na;
var xUp = !isna(pWave) && !isna(pSig) && !isna(hwVal) && !isna(sigVal) && hwVal > sigVal && pWave <= pSig;
var xDn = !isna(pWave) && !isna(pSig) && !isna(hwVal) && !isna(sigVal) && hwVal < sigVal && pWave >= pSig;
var osUp = xUp && hwVal < 20;
var regUp = xUp && hwVal >= 20;
var obDn = xDn && hwVal > 80;
var regDn = xDn && hwVal <= 80;
pWave = hwVal;
pSig = sigVal;

// ── Range money flow: range-weighted directional flow, EMA-smoothed ───────────
persist rngWin = [];
persist rngSum = 0;
var rng = d.high - d.low;
rngWin.push(rng);
rngSum = rngSum + rng;
if (rngWin.length > mfLen) {
  rngSum = rngSum - rngWin.shift();
}
var g = rngWin.length == mfLen ? rngSum / mfLen : na;

persist gWin = [];
persist upWin = [];
if (!isna(g)) {
  var up = !isna(d.close[1]) && d.close > d.close[1] ? 1 : 0;
  gWin.push(g);
  upWin.push(up);
  if (gWin.length > mfLen) {
    gWin.shift();
    upWin.shift();
  }
}
var core = na;
if (gWin.length == mfLen) {
  var sumU = 0.0;
  var sumT = 0.0;
  for (var kM = mfLen - 1; kM >= 0; kM = kM - 1) {
    sumT = sumT + gWin[kM];
    if (upWin[kM] == 1) {
      sumU = sumU + gWin[kM];
    }
  }
  if (sumT > 0) {
    core = 100 * sumU / sumT;
  }
}

persist emaP = na;
var aS = 2.0 / (mfSmooth + 1);
if (!isna(core)) {
  emaP = isna(emaP) ? core : aS * core + (1 - aS) * emaP;
}
var mfVal = isna(core) ? na : emaP;

// ── Ceiling / floor: asymmetric attack/release chasers clamped at the midline ──
persist ut = na;
persist lt = na;
if (!isna(mfVal)) {
  if (isna(ut)) {
    ut = math.max(mfVal, 50);
    lt = math.min(mfVal, 50);
  } else {
    ut = math.max(50, ut + (mfVal > ut ? 0.2 : 0.005) * (mfVal - ut));
    lt = math.min(50, lt + (mfVal < lt ? 0.2 : 0.005) * (mfVal - lt));
  }
}
var utVal = isna(mfVal) ? na : ut;
var ltVal = isna(mfVal) ? na : lt;

// ── Surge: burst wave from the midline while the flow is beyond its ceiling / floor ─
var bullActive = !isna(mfVal) && !isna(utVal) && mfVal > utVal;
var bearActive = !isna(mfVal) && !isna(ltVal) && mfVal < ltVal;
var bofVal = isna(mfVal) ? na : (bullActive ? math.max(50, mfVal - 10) : 50);
var befVal = isna(mfVal) ? na : (bearActive ? math.min(50, mfVal + 10) : 50);

persist prevBullActive = false;
persist prevBearActive = false;
var newBull = bullActive && !prevBullActive;
var newBear = bearActive && !prevBearActive;
prevBullActive = bullActive;
prevBearActive = bearActive;

persist prevMf = na;
var mfCrossUp = !isna(mfVal) && !isna(prevMf) && mfVal > 50 && prevMf <= 50;
var mfCrossDn = !isna(mfVal) && !isna(prevMf) && mfVal < 50 && prevMf >= 50;
prevMf = mfVal;

// ── Divergences: strict 1/1 fractal pivots on the wave, zone-gated, 6-bar close memory ─
var w2 = wave[2];
var w1 = wave[1];
var pivReady = !isna(w2) && !isna(w1) && !isna(hwVal);
var pivBull = pivReady && w2 > w1 && w1 < hwVal && w1 < sens;
var pivBear = pivReady && w2 < w1 && w1 > hwVal && w1 > 100 - sens;

persist bullRefOsc = na;
persist bullRefPrice = na;
persist bullRefPriceT = na;
persist bullRefTime = na;
persist bearRefOsc = na;
persist bearRefPrice = na;
persist bearRefPriceT = na;
persist bearRefTime = na;
persist bullLines = [];
persist bearLines = [];
persist bullChartLines = [];
persist bearChartLines = [];

var divBull = false;
var divBear = false;
var pivTime = d.time[1];

if (pivBull) {
  // lowest close over the 6 bars ending at the pivot bar (offsets 1..6 from here) + its bar
  var pLo = na;
  var pLoT = na;
  for (var jB = 1; jB <= 6; jB = jB + 1) {
    var c = d.close[jB];

  bullRefPrice = pLo;
  bullRefPriceT = pLoT;
  bullRefTime = pivTime;
}
if (pivBear) {
  // highest close over the 6 bars ending at the pivot bar + its bar
  var pHi = na;
  var pHiT = na;
  for (var jR = 1; jR <= 6; jR = jR + 1) {

// ── Reversal detector: travel since the last reversal, in half true-ranges of this bar ─
// Pure price. ref is the close of the last reversal (either side); the first bar seeds it.
// Exact ties (x == threshold) stay quiet: the 1e-9 tolerance absorbs float-division noise.
persist revRef = na;
persist revPrevSide = 0;
var revThr = 0.5 * revFactor;
var revEps = 0.000000001;
var prevClose = d.close[1];
var barRange = isna(prevClose) ? d.high - d.low : math.max(d.high - d.low, math.max(abs(d.high - prevClose), abs(d.low - prevClose)));
var revX = na;
var revDnMinus = false;
var revDnPlus = false;
var revUpMinus = false;
var revUpPlus = false;
if (!isna(revRef) && barRange > 0) {
  revX = (d.close - revRef) / barRange;
  if (revX > revThr + revEps) {
    if (!isna(hwVal) && hwVal > 80 && revPrevSide == 1) { revDnPlus = true; } else { revDnMinus = true; }
    revRef = d.close;
    revPrevSide = 1;
  } else if (revX < -revThr - revEps) {
    if (!isna(hwVal) && hwVal < 20 && revPrevSide == -1) { revUpPlus = true; } else { revUpMinus = true; }
    revRef = d.close;
    revPrevSide = -1;
  }
}
if (isna(revRef)) { revRef = d.close; }

// ── CVD: session-anchored cumulative delta + the higher-frame slope (persist-summed) ─
// (computed while either lane is on: the toggle hides the diamonds, the divergence alerts keep computing)
persist cvd = 0;
persist cvdSession = na;
persist sessionAge = 0;
persist htfBucket = na;
persist htfCur = 0;
persist htfPrev = 0;
persist cvdBullRef = na;
persist cvdBullRefPrice = na;
persist cvdBullRefPriceT = na;
persist cvdBearRef = na;
persist cvdBearRefPrice = na;

persist cvdBearChartLines = [];

var cvdDivBear = false;
var cvdBullPlus = false;
var cvdBearPlus = false;
var cvdValNow = na;
if (flowOn) {
  var sessionId = cvdAnchor == "UTC day" ? floor(d.time[0] / 86400000) : (cvdAnchor == "UTC week" ? floor((d.time[0] - 4 * 86400000) / 604800000) : 0);
  var newSession = isna(cvdSession) || sessionId != cvdSession;
  if (newSession) { cvd = 0; cvdSession = sessionId; sessionAge = 0; cvdBullRef = na; cvdBearRef = na; } else { sessionAge = sessionAge + 1; }
  cvd = cvd + (isna(takerDelta) ? 0 : takerDelta);
  cvdValNow = cvd;

  var bucketId = floor(d.time[0] / (4 * currentInterval));
  if (isna(htfBucket) || bucketId != htfBucket) { htfPrev = isna(htfBucket) ? 0 : htfCur; htfCur = 0; htfBucket = bucketId; }
  htfCur = htfCur + (isna(takerDelta) ? 0 : takerDelta);
  var htfSlope = htfPrev + htfCur;
  // The plus grade is read on closed bars only: the slope includes the bar's
  // own delta and the app re-runs the forming bar on every tick, so a
  // divergence confirmed on the live bar would flip between the base and
  // plus tones (and its connector between dashed and solid) as the tape
  // moves. It keeps the base grade until the bar closes (isConfirmed).

  // the wave divergences' pivot rule applied to the CVD: strict 1/1 fractal confirmed one bar later,
  // lowest / highest CLOSE over the 6 bars ending at the pivot, the previous same-side pivot as
  // the comparison point (every pivot replaces it), both pivots inside one anchor period
  timeseries cvdTs = cvdValNow;
  var c2 = cvdTs[2];
  var c1 = cvdTs[1];
  var cvdPivReady = sidedSeen && sessionAge >= 2 && !isna(c2) && !isna(c1);
  var cvdPivBull = cvdPivReady && c2 > c1 && c1 < cvd;
  var cvdPivBear = cvdPivReady && c2 < c1 && c1 > cvd;
  // chart connectors share the engine's 500-per-kind line cap with the wave connectors (4 FIFOs of
  // 120): FIFO 60 per side here, and never past 490 alive in total (the oldest CVD line goes first)
  var linesAlive = bullLines.length + bearLines.length + bullChartLines.length + bearChartLines.length + cvdBullChartLines.length + cvdBearChartLines.length;
  if (cvdPivBull) {
    var cLo = na;
    var cLoT = na;
    for (var jC = 1; jC <= 6; jC = jC + 1) {
      var cc = d.close[jC];
      if (!isna(cc) && (isna(cLo) || cc < cLo)) { cLo = cc; cLoT = d.time[jC]; }
    }
    if (!isna(cvdBullRef) && !isna(cLo) && cLo < cvdBullRefPrice && c1 > cvdBullRef) {
      cvdDivBull = true;
      cvdBullPlus = isConfirmed && htfSlope > 0;
      if (showCvdDiv && showCvdLines) {
        if (cvdBullChartLines.length >= 60 || linesAlive >= 490) {
          if (cvdBullChartLines.length > 0) { cvdBullChartLines[0].delete(); cvdBullChartLines.shift(); linesAlive = linesAlive - 1; }
          else if (cvdBearChartLines.length > 0) { cvdBearChartLines[0].delete(); cvdBearChartLines.shift(); linesAlive = linesAlive - 1; }
        }
        if (linesAlive < 490) {
          cvdBullChartLines.push(line.new(cvdBullRefPriceT, cvdBullRefPrice, cLoT, cLo, {color: cvdBullCol, width: 1, style: cvdBullPlus ? "solid" : "dashed", pane: "onchart"}));
          linesAlive = linesAlive + 1;
        }
      }
    }
    cvdBullRef = c1;
    cvdBullRefPrice = cLo;
    cvdBullRefPriceT = cLoT;
  }
  if (cvdPivBear) {
    var cHi = na;
    var cHiT = na;
    for (var jD = 1; jD <= 6; jD = jD + 1) {
      var cd = d.close[jD];
      if (!isna(cd) && (isna(cHi) || cd > cHi)) { cHi = cd; cHiT = d.time[jD]; }
    }
    if (!isna(cvdBearRef) && !isna(cHi) && cHi > cvdBearRefPrice && c1 < cvdBearRef) {
      cvdDivBear = true;
      cvdBearPlus = isConfirmed && htfSlope < 0;
      if (showCvdDiv && showCvdLines) {
        if (cvdBearChartLines.length >= 60 || linesAlive >= 490) {
          if (cvdBearChartLines.length > 0) { cvdBearChartLines[0].delete(); cvdBearChartLines.shift(); linesAlive = linesAlive - 1; }
          else if (cvdBullChartLines.length > 0) { cvdBullChartLines[0].delete(); cvdBullChartLines.shift(); linesAlive = linesAlive - 1; }
        }
        if (linesAlive < 490) {
          cvdBearChartLines.push(line.new(cvdBearRefPriceT, cvdBearRefPrice, cHiT, cHi, {color: cvdBearCol, width: 1, style: cvdBearPlus ? "solid" : "dashed", pane: "onchart"}));
          linesAlive = linesAlive + 1;
        }
      }
    }
    cvdBearRef = c1;
    cvdBearRefPrice = cHi;
    cvdBearRefPriceT = cHiT;
  }
}

plotLine(value=meterValTs, colors=[confBullCol, confBearCol, slate, "transparent"],
  colorIndex=showMeter ? meterIdx : 3, width=meterWidth, showPriceDisplay=showMeter,
  label=["Confluence Score"],
  desc=["Confluence score (0..100): five signed trend elements on a 100/14 lattice; above 50 bullish, below 50 bearish"]);
if (showMeter) {
  fillBetween(series1=meterValTs, series2=midline, color=meterVal > 50 ? confBullCol : confBearCol, opacity=0.18);
}

// the score dial: 110 one-unit boxes right of the last bar + a pointer at the reading
persist gaugeBoxes = [];
if (showGauge && isLastBar && !isna(meterVal)) {
  while (gaugeBoxes.length > 0) { gaugeBoxes[0].delete(); gaugeBoxes.shift(); }
  var gx1 = d.time[0] + 2 * currentInterval;
  var gx2 = d.time[0] + 4 * currentInterval;
  for (var gi = -5; gi < 105; gi = gi + 1) {
    var gCol = colorGradient(value=gi + 0.5, range=[-5, 105], colorStops=[confBearCol, slate, confBullCol]);
    gaugeBoxes.push(box.new(gx1, gi + 1, gx2, gi,
      {bgcolor: opacity(gCol, 85), borderColor: "transparent", borderWidth: 1, borderStyle: "solid"}));
  }
  gaugeBoxes.push(box.new(d.time[0] + 1.4 * currentInterval, meterVal + 0.8, d.time[0] + 4.6 * currentInterval, meterVal - 0.8,
    {bgcolor: meterVal > 50 ? confBullCol : (meterVal < 50 ? confBearCol : slate), borderColor: "transparent", borderWidth: 1, borderStyle: "solid",
     tooltip: "Confluence score reading"}));
}
